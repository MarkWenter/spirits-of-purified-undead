# 污秽之雨第四部分

版本：1.1.0-blighted-rain.5。Forge 1.20.1、NeoForge 1.21.1 均实际实现。

## 本次内容

- 无头的骑士改为实体收尖盾牌轮廓，外侧纹章、内侧不透明灰白背板和握柄；去除旧透明方框和游离封边，采用原版盾牌手持/格挡变换。继续使用 ShieldItem 的格挡逻辑、耐久、附魔及5点持有护甲。
- 伊莱恩：副手疲惫的心，累计击杀溺尸、秽鬼溺尸或秽鬼女巫；默认3只，混合计数。沿用旧计数存档键。
- 法腾：原有僵尸村民治愈路线继续有效，实际治愈秽鬼村民也走同一奖励及离线补发流程。
- 海尼尔：保留至少3种负面效果（可配置）的前提，目标改为 blighted_creatures 标签中的任意秽鬼；普通僵尸不再满足。
- 创建世界的游戏规则→更新分组增加“是否启用永雨”，默认开启；关闭使用正常天气，以此设置创建的新世界中每位玩家首次登录获得一个秽雨纹章。重登/死亡不重复领取，旧世界不追溯赠送。自然雨天仍可能触发污秽之雨。
- 原天气管理指令和新游戏规则同步控制永雨状态。既有世界的雨事件存档、自定义设置保留。
- 洁白莲花与猩红莲花可以放置为植物，草方块、泥土标签方块、耕地可支撑；采集回原物品。新增独立交叉面植物模型和32×32贴图。原手持/物品栏贴图及模型不改，白莲花回复50%最大生命、红莲花力量IV持续50秒的原有食用功能保留。

白巫女手记本轮不更新。

## 资源制作

盾牌正面、白莲花植物、红莲花植物分别由 imagegen 生成；像素处理保留透明轮廓/不透明盾面并调整到实际图集尺寸。植物资产只写入 textures/block 和 models/block。盾牌纹理位于 item 图集路径以保证普通物品模型正确加载。

新资源为重新绘制，未把用户参考图文件加入公开仓库。Forge仅更新“污秽之雨更新”分支，不合并main。
