# 污秽之雨测试修正 · 1.1.0-blighted-rain.2.2

## 五项修改

1. 溺尸红眼扩展覆盖原版两行三列的眼眶范围，去除底层遗留青蓝边缘；保留外层皮肤与透明区域。
2. 所有转化仍统一掉落装备。原版骷髅等能重新拾取，原版掠夺者却只走旗帜拾取路径。新增秽鬼掠夺者空手拾弩逻辑，保留耐久/附魔/组件，消费地面原物品而不复制，拾得弩死亡时可掉落。无弩时使用近战目标，有弩后退出近战并恢复原弩 AI。禁用生物破坏等原版拾取限制仍生效；没有强制送一把新弩。
3. 秽鬼村民仍使用僵尸村民模型/敌对逻辑；从原版绿色皮肤区域映射为暗褐红色，保留衣服、红眼和侵蚀纹。逐像素修正纳入 `scripts/blighted-textures/rebuild.py`，两版同步。
4. 新增全部秽鬼实体的刷怪蛋：Forge 17 种、NeoForge 18 种（含沼骸），包含原有傀儡与国王。沿用相应原版蛋的底色/斑点，第三层叠加不受染色影响的暗红裂纹；使用加载器延迟刷怪蛋实现。
5. 创建独立“涤净亡魂”创造栏 `purified_undead:main`，标题图标使用秽鬼化状态纹理。原有物品、石板、铸造器、九种纯净灵药形式与刷怪蛋置于该栏。白巫女手记仅迁移创造栏归属，教程内容不改。进度专用图标及栏位专用图标不作为可拿取玩法物品展示。

既有实体/物品 ID、存档格式与网络协议 12 不变；新物品使用新增 ID。只推送 Forge 的污秽之雨更新分支，不合并主分支。
