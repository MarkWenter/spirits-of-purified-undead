# 污秽之雨第四部分补充 · 1.1.0-blighted-rain.6

Forge 1.20.1、NeoForge 1.21.1 同步实现。网络协议升为13；服务器和客户端应使用同版。

## 修复与功能

- 静雨信标生效时，纹章强制事件自然结束或被停止后恢复正常天气，暂停自然事件冷却。保留未加载区块的激活记录，不强制加载区块；重新加载后核对基座与红石。信标未激活亮度4、成功激活亮度15。
- 新增 `config/purified_undead-accessories.toml`，集中配置护身符、八组战士、八件白巫女遗物、莉莉手记、闪耀的守护宝具。旧 common 中饰品数值、旧 slate 中守护宝具血量设置首次启动自动迁移，源文件另存 before-accessories 备份，已存在的新文件不覆盖。契约槽位、获取路线、材料掉率仍在 common；石板记忆技能参数仍在原独立 slate 文件。配置单位及清单见 [饰品配置](PART_4_SUPPLEMENT_CONFIG.md)。
- 控制选项的“涤净亡魂”中新增“开关费林协同攻击”和“开关二段跳与空中冲刺”，默认未绑定。原技能默认开启；绑定后按键切换，状态由服务器保存，死亡/重登保留。关闭费林只关闭协同剑气，不移除契约与其他被动；姐妹开关控制二段跳和空中冲刺，不影响护甲或墙面抓握。
- 按《白巫女手记3》加入污秽之雨、墓穴泞尘、纹章、红宝石、生熟污秽肉、静雨信标、悬崖村的少年、无头的骑士共9条；更新疲惫的心、海尼尔、法腾说明。中英文均为62条150页，新增秽鬼武器分类，其他内容最后。莲花原手持图不改。
- 雪中红色改为纹理坐标上的局部平滑斑点，去除依赖绘制顺序的整片变色。雨粒子只在生成时混合既有颜色，不在每刻覆写其他模组颜色；无事件时提前退出视觉计算。
- 雨伤覆盖模组 Mob，不再只依赖原版白名单。保留亡灵（幻翼例外）、秽鬼、归属保护、免疫标签/配置和正常受伤事件，不强制绕过其他模组的伤害免疫。

## 审查与优化

- 村民避雨只接受可到达路径；失败重试退避5秒，单次最多检查4个附近床位，清理失效自有目标；不按每刻寻路。
- 悬崖村的少年以20刻为批次累计携带恢复时间，减少物品数据改写与同步；仍约30秒恢复一点。保存的异常非有限伤害值回退到默认，正常附魔不变。
- 铸造配置迁移完整验证后才通过临时文件替换保存；验证失败不回写迁移。配方数量/同步大小和物品ID检查保留。
- NeoForge额外掉落的抢夺读取与原版一致，支持任何活体攻击者，并继续经过现有法腾虚拟抢夺桥接。
- 检查请求权限、只修改发送者的偏好、动作限速、投掷物归属/PVP、配方同步、可选JEI边界与区块生命周期。本轮未确认可利用的安全漏洞；这是针对污秽之雨及接入点的审查，不等于全仓库和所有模组组合的安全保证。
