# 污秽之雨第一部分 · 本体实现

日期：2026-10-14。Forge 1.20.1 / NeoForge 1.21.1，候选版本 `1.1.0-blighted-rain.1`。本文件记录已实现行为，用户最新要求优先于早期设计。白巫女手记未改。

## 天气与世界状态

默认锁定主世界雨天，雷暴由原版天气规则继续控制。仅主世界存在污秽事件；普通雨、污秽雨和污秽雪按原版当前位置降水类型区分，NONE 区域不改变。

每世界每秒一次 0.1% 概率，在雨/雷雨、至少一名玩家处于主世界且阶段为就绪时判定。预警、落雨和冷却期间都不抽取概率。游戏时间暂停时不重复抽取；多人不增加触发频率。

`就绪 → 15 秒预警 → 5—10 分钟落雨 → 15 分钟冷却 → 就绪`。

预警提示「污秽之雨即将降下……」，开始村民避险和渐变画面，尚不结算效果/伤害/转化。落雨期间处于无计时冷却；**事件结束后**才开始 18000 游戏刻冷却。结束立即提示「污秽之雨暂时停下了……」，恢复普通降水。原有雨赋予的药水效果自然到期。

状态、期限、天气锁及事件启用状态保存在主世界 SavedData；游戏暂停/服务器关闭不消耗时间，睡眠或修改昼夜时间不跳过冷却。玩家登录、重生、换维度同步当前状态，退出清理客户端状态。

有效等待期望为 16 分 40 秒，加平均落雨 7 分 30 秒、预警 15 秒和结束后冷却，平均两次触发约隔 39 分 25 秒。这是统计期望，并非保证周期。

## 暴露、玩家与生物

天空可见、原版 MOTION_BLOCKING 高度图及身体/顶部共同判定实际暴露。屋顶和玻璃屋顶可挡雨雪；水面以下不计入暴露。不会因某个生物接触浅水便给予永久免疫。

玩家露天每秒刷新急迫 I、力量 I、秽鬼化各 10 秒，**不受到污秽降水伤害**。复用原有秽鬼化与契约奖励链；自然获取开关仍有效。极限模式所有来源共享一次秽鬼化保命机会，消费记录持久化并随玩家换体保存，旧存档已取得契约也不再获得新的机会。

受影响生物每 25 刻受 1 点专属魔法伤害，即中毒 I 的基础扣血速率，但可致死；走正常伤害/抗性/死亡流程。受影响类型采用可扩充实体标签 `purified_undead:blighted_rain_affected`，免疫标签为 `purified_undead:blighted_rain_immune`。Forge 的目录为 `tags/entity_types`，NeoForge 为 `tags/entity_type`。保留原有 Ulv 护甲穿透标签。

原版所有者 UUID、驯服关系及狐狸信任 UUID 提供保护，主人离线也有效。标准 TamableAnimal 的第三方生物同样保护；保留专门归属适配入口，未对所有第三方自定义 NBT 自动猜测归属。免疫同时阻止伤害及本次环境转化。

可选配置：实例 `config/purified_undead-blighted-rain-immunity.json`，例如 `{"immuneEntityTypes":["minecraft:villager"]}`。服务端启动加载，不存在即空白名单；限制大小、条目数及合法 ID，错误配置保留已有有效列表并报告。完整天气配置和仪式仍留后续。

村民在预警及落雨阶段尝试使用 HOME/附近可达且有遮挡的床 POI、HIDE 活动避难；每秒有限目标/寻路检查，无传送或伪造灾厄袭击。屋内村民可就地避险，保留 RAID/PANIC/NoAI；没有可达遮挡地点仍可能受伤。结束释放本模块目标并恢复日程。

## 转化与掉落

铁傀儡→污秽傀儡、唤魔者→污秽国王：每暴露一刻 +1，没有增加时每刻 -1，最低 0；达到 100 转化。仅这两类候选做逐刻暴露检查，普通伤害每 25 刻，玩家效果每秒，不扫描未加载世界。卸载期间不增加进度，加载后按时间差衰减残余。

点击怨念污秽与降水共用已有实体创建/状态保留服务。先成功加入新实体再移除原实体，失败保留并限频重试；达到阈值的转化先于该刻伤害，不发额外战士奖励。

污秽雨作为最终致死来源、且从未成功受玩家伤害的生物取消标准物品掉落；曾受玩家成功伤害者保留正常掉落。吸收心受到损失也算有效伤害，取消/无敌/未造成损失不算。记录持久保存并在本模组转化时转移；不能追溯升级前已经丢失的攻击历史。仅物品掉落按本次要求处理，不清除附近物品或伪造玩家击杀归属，经验保持原规则。

## 客户端与接口

原版雨雪绘制沿用遮挡、光照和密度，通过专用天气着色器将蓝色雨丝改为灰色并夹少量红色；雨落地粒子、云色和雾色跟随预警渐变。结束没有画面缓冲。画面只读服务端状态，不决定效果。

云/雾变化与提示提供额外表现，但任意光影可能替换雨雪、云和雾，不能承诺所有光影均可见；第三方光影组合未全面验证。客户端专用代码和 Mixin 与公共服务端入口隔离。

模块拆分为纯状态模型、SavedData、天气控制、暴露/归属/免疫、村民避险、效果、加载器事件适配、管理员指令及客户端状态/渲染。加载器只保留 API 差异，不引入通用模块框架。未来启停仪式走控制入口，其他转化和归属适配可接独立服务。公共附属 API 仍为 v1，本体不反向依赖附属。新增服务端天气包使本体网络协议从 10 升至 **11**，客户端与服务端须配套更新。

## 管理员测试指令

权限等级 2；在主世界执行，沿用 `/purifiedundead` 根指令。

| 指令 | 行为 |
| --- | --- |
| `/purifiedundead rain status` | 当前阶段、剩余秒数、天气锁状态 |
| `/purifiedundead rain start` | 正常 15 秒预警，随后随机 5—10 分钟落雨 |
| `/purifiedundead rain start 60` | 15 秒预警，随后 60 秒落雨；参数允许 1—600 秒 |
| `/purifiedundead rain stop` | 停止预警/落雨，进入 15 分钟冷却 |
| `/purifiedundead rain reset` | 测试专用：停止当前事件并清除冷却 |
| `/purifiedundead rain weather vanilla` | 暂时恢复原版天气策略，保存在世界中 |
| `/purifiedundead rain weather locked` | 恢复默认持续雨天策略 |

start 对晴天、错误维度、事件已占用、冷却、事件禁用分别报错，不暗中把晴天改成雨天，也不跳过冷却。测试晴天错误可先设 `weather vanilla`，再 `/weather clear`，然后执行 start；恢复测试时 `/weather rain`、reset、start。reset/weather 是隔离测试辅助，不代表后续仪式玩法已完成。
