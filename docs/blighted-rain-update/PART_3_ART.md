# 第三部分贴图制作记录

模式：内置 imagegen（非 CLI/API）。项目最终资源位置：`src/main/resources/assets/purified_undead/textures/item/` 与 `textures/block/still_rain_*.png`，NeoForge 同路径。

逐项生成提示约束：

| 资产 | 提示词核心要求 |
| --- | --- |
| 秽雨纹章 | 单个灰铁椭圆徽章，扭曲深色水滴，暗红侵蚀纹，32×32 逻辑像素，透明背景 |
| 墓穴泞尘 | 原版火药形状的骨灰色灰烬堆，灰白碎屑、炭灰阴影，16×16 逻辑像素 |
| 污秽红宝石 | 保留绿宝石切割形状，整体红色，黑色裂纹与暗红侵蚀，16×16 逻辑像素 |
| 静雨信标 | 原版玻璃/黑曜石/核心三块 UV 横向图集；玻璃暗红、底座灰黑裂纹、核心淡玫瑰色；保持透明区域与各块布局 |
| 悬崖村的少年 | 用户参考图重绘为灰白卷曲轮廓、锯齿嘴部、少量暗红裂纹；32×32 像素、透明背景 |
| 无头的骑士 | 用户参考盾徽重绘，灰白盾面、深色骷髅与暗红裂纹；正面视图、32×32 像素，去掉背景与漂浮光点 |
| 污秽肉 | 原版肉类可辨识轮廓，灰白肉、淡灰脂肪、深灰边缘；16×16 像素 |
| 熟污秽肉 | 基于生肉生成图修改，仅改成灰暗红熟肉，保持轮廓及透明背景 |

像素校准：透明度阈值 128，按不透明包围盒裁切；最近邻缩放至 16 或 32 像素并保留边缘间距。信标图集按三等分分别裁切至 16×16，原版模型 UV 不变；实体投掷物使用原版灰石方块半尺寸渲染。盾牌侧面与把手使用灰色原版材质，正面使用生成纹样。

最终截图保存在开发实例 `run/blighted-rain-part2-client/screenshots/rain-part3-*.png`。参考图及原始大尺寸生成图不作为运行依赖，不打包到发布 JAR。
