# 秽鬼贴图重绘 · 1.1.0-blighted-rain.2.1

本次仅更新污秽之雨第二部分新增生物的贴图和画面验证。Forge 1.20.1 与 NeoForge 1.21.1 分别落地；沼骸仅在 NeoForge。原有秽鬼傀儡、秽鬼国王的贴图保留。玩法、注册 ID、存档格式、网络协议 12 和白巫女手记均不变。

## 制作方式

弃用上一轮临时秽鬼纹理，以各版本 Minecraft 原版客户端贴图重新开始。使用内置 imagegen，分别编辑 16 种基础 UV 及羊毛、溺尸外层、流浪者衣层、沼骸苔藓层，首轮共 20 张草稿，随后按画面反馈追加村民头部重绘和独立衣层编辑，共 22 次生成、21 组最终校准纹路。每张输入是原版 UV 的最近邻放大图；原作画集作为暗色裂纹、暗红侵蚀与红眼的风格参考，没有直接裁切画集用于游戏贴图。

生成结果经过像素脚本处理：提取裂纹与侵蚀纹，恢复到原版尺寸和坐标；原版底色、五官、衣物、毛色与斑块保持辨识度。所有透明通道逐像素与原版相同。移除生成图中误画的五官和鞍具侵蚀，按原版眼部坐标重绘红眼。僵尸/骷髅系列眼部位于 y=12，村民/灾厄村民/女巫位于 y=14（坐标从零开始）；动物单独核对。

马的七种毛色与斑纹层共享校准后的纹路，底色来自各自原版资源；鞍具恢复原样。村民的职业和群系衣层沿用原版服饰并叠加校准纹路，等级徽章保留原样。未使用的附带纹理恢复原版，避免继续保留上轮的临时花纹。羊毛仍遵循原版染色，深色染色时纹路对比会随原版乘色降低。

## 可复现资料

- [重建脚本](../../scripts/blighted-textures/rebuild.py)、[资源映射](../../scripts/blighted-textures/spec.json)及同目录 `masks/` 保存本轮校准后的 imagegen 纹路。
- 脚本依赖 Pillow 与 numpy，接受 `--forge-jar`、`--neo-jar`，输入用户合法安装的对应版本原版客户端 JAR；只提供一种参数时只重建该版。
- 原始生成图、校准过程和本地对照图保存在工作区 `art/blighted-repaint/`，不放入安装包或公开仓库。
- [提示词记录](TEXTURE_PROMPTS.md)记录本轮生成约束与各生物差异。

成品与本轮验证结果见 [验证记录](TEXTURE_REPAINT_VALIDATION.md)。整体污秽之雨更新仍未定稿，Forge 只提交到“污秽之雨更新”分支。

## 衣层与头部增强

针对衣服遮盖导致侵蚀不明显的反馈，追加 imagegen 村民头部及平原服饰 UV 编辑。头部纹路按相同 UV 转移到掠夺者、卫道士、女巫，保留原版眉眼行与独立鼻子。职业与群系外层直接使用衣层专用纹路，不再仅依赖底层皮肤。溺尸、流浪者外层及僵尸、尸壳上衣也补入校准后的胸前裂纹。每层保持原版透明度，职业等级徽章不改。
