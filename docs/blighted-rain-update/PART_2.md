# 污秽之雨第二部分：预警音效与秽鬼生物

2026-10-15；两版候选版本 `1.1.0-blighted-rain.2`。Forge 1.20.1、NeoForge 1.21.1 均在各自实际工程实现。整体更新仍未定稿，GitHub 仅更新 `污秽之雨更新` 分支，不合并主分支。

## 本轮规则

- 15 秒预警消息出现时，对当前主世界玩家同步播放项目作者提供的预警音效。音频转换为 Ogg Vorbis，未截断；新进入世界或切换维度的状态同步不会重复播放旧预警。
- 一般转化阈值由累计 100 刻改为 **200 刻（10 秒）**，遮挡、水中及事件结束时仍逐刻衰减。原生亡灵免疫雨伤仍能积累转化进度。村民和鸡是例外：只在污秽之雨伤害致死时转化，转化后恢复到新生命上限；其他伤害致死不会转化。
- 所有亡灵免疫污秽之雨伤害，**幻翼除外**。原有玩家、所属生物、白名单、屋顶和水下豁免继续有效。玩家始终不受雨伤。
- 所有秽鬼加入 `purified_undead:blighted_creatures`，并加入 `minecraft:undead`；Forge 同时使用原版 `MobType.UNDEAD`。秽鬼不会因阳光燃烧；这不增加一般火焰或岩浆免疫。
- 新增秽鬼僵尸、骷髅、溺尸、尸壳、流浪者、村民、掠夺者、卫道士、女巫、猪、牛、羊、鸡、马、驴。NeoForge 1.21.1 另有秽鬼沼骸，Forge 1.20.1 不注册该类型。
- 秽鬼村民继承僵尸村民，成为敌对生物；保留幼年状态、职业和相应原版数据，不提供活村民交易。僵尸及其变种保留幼年状态；羊保留颜色/剪毛状态，马保留毛色和斑纹。
- 新生物生命上限为原实体上限的两倍，存活转化时按原有血量比例同步，因此当前血量也翻倍。原有生命属性附加值参与缩放，避免读取存档后重复翻倍。
- 原本会攻击的新增生物攻击节奏加快一倍。近战间隔、弓的拉弓和射击间隔、弩的蓄力和发射延迟、药水/三叉戟攻击间隔分别接入原版 AI。弩的物品装填判定也按加快后的时间处理，保证真实装填与发射。原版生物和原有秽鬼傀儡/国王不额外套用这些加速。
- 秽鬼女巫保持原版饮药行为，自我治疗时改用可治疗亡灵的伤害药水，避免亡灵身份导致治疗药水自残。
- 保留原生物原版掉落，新增生物另独立掉落 **1 个污秽碎片**。原有随机污秽碎片规则仍按原生物资格处理，避免动物仅因亡灵身份而新增旧的随机掉落；数据包显式添加的掉落资格仍受支持。剪毛羊保留羊肉掉落，未剪毛羊保留对应颜色羊毛。尊重 `doMobLoot` 及其他模组取消掉落事件。
- 原有铁傀儡/唤魔者继续可由怨念污秽转化；新来源中只允许原本敌对的候选生物使用该物品转化。鸡、村民、猪、牛、羊、马、驴不接受此途径。原有契约要求继续有效。
- 转化先确认新实体成功加入，再掉落旧装备、分离骑乘双方并移除旧实体。新实体可以按原版拾取机制重新拾取装备；猪/马的马鞍与马铠同样掉落，不复制残留。其他模组拒绝新实体生成时保留原实体和装备。
- 移除转化时自动设置的名字，并清理旧存档中本模组自动生成的傀儡/国王翻译名字。玩家真实命名牌名称保留。

## 代码接入

新注册和各原版派生实体位于 `blightedrain/mob/`；`BlightedMobConversions` 负责来源映射、状态复制和替换事务，原有 `progress/BlightedConversions` 作为旧傀儡/国王接入边界。天气状态机、所有权检测及伤害仍沿用第一部分模块。鸡/村民的死亡转化及独立碎片由加载器事件适配层接入。

攻击钩子仅对 `BlightedVariant` 生效，不改变其他模组的生物；视觉钩子只替换这些实体返回的、明确列入清单的原版纹理路径。其他模组材质、装备渲染及原版生物保持原样。驴使用独立渲染器解决原版渲染器按精确原版实体类型查找贴图的限制；骨骼模型沿用原版。

贴图按用户批准的逐像素绘制与合成制作，在原版图集上加入暗红裂纹、块状污秽纹路与红眼，原始尺寸、UV 和透明区域保持一致。覆盖溺尸/流浪者外层、羊毛、村民职业/群系以及马匹毛色/斑纹。当前贴图保留为临时版本；按用户最新要求，后续单独调整，不在本轮继续进行美术修改。本轮参考图片不随源码分发。预警音效源由项目作者提供，沿用项目素材许可说明。

本体网络协议更新为 **12**，客户端与服务端需一起更新；附属 API v1 不变。已有注册 ID 与天气存档键保持兼容。白巫女手记与附属模组没有修改。更多秽鬼特性、解除仪式、完整天气设置仍按后续需求准备。

## 测试入口

沿用 `/purifiedundead rain` 指令。新实体可用 `/summon purified_undead:blighted_<原版英文名>` 直接检查；沼骸只有 NeoForge 的 `blighted_bogged`。先进入雨天，再用 `/purifiedundead rain start` 检查预警与转化；晴天拒绝开始事件。完整验证范围见 [第二部分验证记录](PART_2_VALIDATION.md)。
