# v0.46.3 · Forge 47.3.22 兼容

将 Forge 1.20.1 的实际编译基线和加载最低要求从 47.4.12 调整至 47.3.22，允许范围为 `[47.3.22,48)`。

发现并修复两处接口障碍：污秽铁傀儡、污秽之王的原版掉落表引用使用了此旧版尚未提供的 `ResourceLocation.withDefaultNamespace`。改用 `fromNamespaceAndPath("minecraft", ...)`，生成的资源标识完全相同，掉落行为不变。

Curios 5.14.1、GeckoLib 4.8.4、Patchouli 1.20.1-85、Apothic Attributes 1.3.7、Placebo 8.6.3 的加载声明均允许此版本，保留现有前置。本次仅更新 Forge 成品为 0.46.3-dev；NeoForge 1.21.1 仍为 0.46.2。

保留此前 JEI 空模板锻造修复、可选亡灵兼容以及石板更新功能。配方、属性、注册 ID、美术及白巫女手记正文不变。
