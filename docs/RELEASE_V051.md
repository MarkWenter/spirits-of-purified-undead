# v0.51.0 · 整合包清空收魂名单时的兼容修复

Forge 1.20.1 与 NeoForge 1.21.1 同步实现。

- 只读核对确认神秘启旅已加载 0.50.0；该包 KubeJS 的 soul_hunter_weapon.js 调用 removeAll，清空 Malum 收魂武器标签后只加回六件指定武器，移除了秽鬼之守护。原镰刀正常收魂与此一致。
- 当击杀者主手为秽鬼之守护且该武器缺少 Malum 原生收魂标签时，在死亡事件中补充原生精魂暴露资格，后续数量、精魂劫掠及无魂/刷怪笼限制仍由 Malum 处理。剑刃、剑气与费林协同补刀均支持。
- 正常标签环境直接跳过补救，不恢复整合包禁用的其他武器，不添加全局收魂伤害类型，不重复生成掉落。
- 新配置 purified_undead-common.toml 的 compatibility.guardianMalumSoulHarvest，默认 true；可关闭补救，继续完全遵循整合包标签。
- 仅死亡时检查；无每刻扫描、周边实体查询或任务队列。可选 API 查找一次缓存，缺失/不兼容时停用补救并仅报告一次，普通战斗保留。

本版不改剑气速度、覆盖范围、伤害、配方、贴图或白巫女手记。Forge 最低版本仍为 47.3.22。详情见 [验证与性能说明](purification-update/GUARDIAN_051.md)。
