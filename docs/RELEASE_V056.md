# v0.56.0 — 规范与兼容性审查

本次在保持原有玩法、配方、伤害、存档及配置格式不变的基础上，完成两版工程规范整理与已确认兼容风险修复。Forge 最低要求仍为 47.3.22；白巫女手记正文不变。

- 五个战利品/击杀条件注入改为可串联包装，保留原调用链，降低与其他模组修改同一位置时的冲突风险。
- 缓存 Patchouli 手记接口，接口失配只报告一次；移动同步拒绝非法数值，重复移动请求限制昂贵的装备检查和位置纠正。
- 扩展进度通知故障与游戏进度隔离，自身重复日志限频；Forge 追忆身份检查从八次列表遍历优化为一次。
- 两版 508 个业务及开发测试 Java 文件统一格式，添加固定版本工具校验及规范说明。除明确列出的修复和测试外，其余 Java 变化均经非注释标记比对确认仅为格式。
- 生产源码与本地可查证的 3891 个第三方源码文件比对未发现候选重复片段；不将该有限检查宣称为全部代码原创性证明。第三方素材及库继续保留独立许可。

Forge 本体内嵌官方 MIT 许可 MixinExtras 0.5.3，玩家无需新增安装步骤；NeoForge 使用加载器已有库。原有五个外部前置不变。不要安装开发构建中的 `-slim.jar`，交付目录和本次 Release 均使用完整本体。
