# v0.36.0 — 跟随光点与可选动态照明

包含 v0.35.0 的可选 Patchouli 白巫女手记：污秽碎片与书无序合成，四章、25 条目、47 页；未安装 Patchouli 时不添加该配方。

新增古老民族之契的灰红色跟随光点彩蛋，亮度随佩戴的不死战士数量增加，最高 15。静止时在左前方漂浮，移动时追赶，最大跟随距离 4 格。饰品提示与手册正文不介绍此彩蛋。

可选 RyoamicLights 联动照亮地形，并验证 Oculus/Iris 光影组合；不增加强制前置。没有动态光源扩展时保留光点、光晕和少量粒子。客户端限流、近处优先，不增加服务端跟随实体或光照更新，不改变刷怪和作物生长。

详见 [兼容与性能边界](WISP_COMPATIBILITY.md)。两版独立构建；本仓库发布 Forge 1.20.1 成品，NeoForge 1.21.1 成品保存在本机对应版本目录。

Forge 1.20.1 安装 `purified_undead-0.36.0-dev.jar`；NeoForge 1.21.1 安装 `purified_undead-1.21.1-0.36.0-neoforge-dev.jar`。替换对应旧版主模组 JAR。原有必需前置保持不变。第三方动态光源及光影包另行安装，不包含在本 JAR 中。
