# v0.44.0 · 石板更新：纯化铸造器

两版新增纯化铸造器、石中剑方块外观、四槽界面、法腾与伊莱恩手臂装饰，以及剑形进度与工作外观接口。

上方漏斗输入原料，面对正面时的左右两侧分别输入对应燃料槽，下方只提取成品；朝向随摆放旋转。原石（可用深板岩原石）围绕上中铁剑、正中红石粉有序合成。

本阶段仅完成工作方块基础，不定义加工配方、燃料种类或消耗，不自动生产。已有物品、战斗玩法及白巫女手记正文不变。详细内容见 [石板更新](slate-update/README.md)。

客户端与服务端需同时替换对应版本的本模组 JAR，前置依赖不变。

验证：Forge 122 项、NeoForge 124 项单元测试通过；两版四朝向漏斗、库存保存、拆除掉落、合成配方与实际客户端进度/外观检查通过。详细范围见 [验证记录](slate-update/VALIDATION.md)。
