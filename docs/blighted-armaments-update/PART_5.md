# 秽鬼武装第五步 · 秽鬼之守护

Forge 1.20.1 与 NeoForge 1.21.1 的开发版本均为 `1.3.0-armaments.5`。

在 3×3 工作台的第 2、5、8 格依次放入纯净触碰、无垢剑、下界合金锭，其余格留空，产出一把带经验修补 I 的秽鬼之守护。配方 ID 为 `purified_undead:blighted_guardian`，白巫女手记的合成页直接读取该配方。条目开头的铸造描述已同步。

两版的 `purified_undead:center_column` 配方使用原版有序配方的数据字段和结果格式，将完整九格布局提供给配方展示。NeoForge 1.21.1 在原版裁去空列时记录中列位置，并区分自动合成器的中列查询缓存，防止移动同一列材料后误用先前结果。

息金斧、息金锄、无垢斧、无垢锄的贴图均从上一版成品顺时针旋转 90°。物品栏和手持模型使用同一张贴图。

本地回归记录位于 `outputs/armaments-5/`。检查中列成功、左右列失败、额外物品与旧配方被拒绝，以及合成品的经验修补。客户端另核对工具方向与手记配方跨页。
