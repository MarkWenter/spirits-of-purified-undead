# 1.1.1-hotfix.1：问题2稳定性边界修复候选

本候选对应用户定义的“问题2”（全模组稳定性边界扫描），Forge 1.20.1 与 NeoForge 1.21.1 分别实现。网络协议仍为13。Forge仅进入 `1.1hotfix` 分支，不合并main，不创建正式Release。

## 与问题1的范围区分

“问题1”是 AMD + Oculus 的原始 GLSL 编译兼容报告。本候选不改 vsh/fsh、fog 导入或变量命名，不声称修复该编译根因。这里修复的是其暴露的通用异常传播问题：天气着色器不可用时允许客户端继续加载并使用原版着色器；下一次资源重载可重新尝试。

## 正常体验约束

不修改伤害系数、掉率、配方、注册ID、既有存档键、技能时序、贴图、手记或前置依赖。正常路径继续应用同一暴击算法、天气效果、物品转换和奖励规则。新增日志限频，可选功能的错误不会逐帧刷屏。奖励物品仍即时进入背包，独立的显式同步移到下一活跃刻；通常菜单的正常同步也会发送该变更。

## 验证

本轮新增独立计算/配置回归，以及只在smoke source set中的实际游戏故障注入：背包插入后提交失败、未知物品恢复、同步异常后的奖励去重、装备入场被取消的转换回滚与正常转换精确掉落。故障注入Mixin不得进入发布JAR。

最终验证：Forge 138项、NeoForge 139项单元测试通过，均无失败/错误/跳过。两版独立开发服务器完整回归及 `FAILURE_BOUNDARIES_OK` 通过；两版实际发布JAR主菜单、全部修改目标类及资源重载通过；故意无效GLSL实际命中后仍完成启动和重载。NeoForge故障通过仅修改隔离测试JAR副本的着色器实现，候选包未修改。两版实际雨雪场景 `BLIGHTED_RAIN_CLIENT_OK`、`RAIN6_TOGGLE_NETWORK_OK` 通过，已核对本轮画面。安装包不含smoke/test类，玩法数据、贴图和原始GLSL内容一致性检查通过。

详细日志、故障测试说明及SHA-256保存在本地 `outputs/hotfix2-2026-10-25/VALIDATION.md`。AMD硬件组合未覆盖，不能据N卡验证宣称问题1已解决。

## 边界限制

本候选对本模组拥有的背包槽、保留记录、实体和显示资源建立恢复/降级路径，不承诺能撤销第三方在回调中执行的任意外部副作用。若核心回滚也被第三方拒绝或失败，将明确终止该不安全流程，而不是掩盖损坏继续重试。可选视觉钩子在冲突环境中降级时会失去对应附加效果，正常环境仍启用。


## 1.1.1-hotfix.2：性能与回滚边界复查后的修正

继续同一 `1.1hotfix` 分支，两版协议仍为13，保留hotfix.1的稳定性保护。没有调整玩法、物品ID、存档键、配方、美术或着色器。前述hotfix.1验证属于上一候选，不能视为本轮验证。

- **无空间时避免整包快照。** 生存背包没有空槽、也没有可合并槽时直接返回未送达，pending与原始保留记录不变；创造模式原有吞余量语义保留。实际可能插入时仍复制全部库存槽，插入或提交失败仍完整回滚。没有以减少快照来削弱真实事务的保护。
- **逐项提交但不反复复制整张保留表。** 仅在物品数量实际变化时序列化余量，序列化成功后才修改服务器线程拥有的原始NBT条目；空余空间不足时不重写。逐项送达即移除/更新对应记录，后续条目失败不撤销前项、不重复发放。新增死亡保留同样先序列化单项再追加，未知条目不丢弃。跨重生复制仍保留独立深拷贝。
- **NeoForge使用无副作用的解码结果。** 使用相同ItemStack CODEC及注册表上下文读取result，不调用会在解码失败时逐次输出ERROR的parseOptional。空结果仍保留原始条目，每秒可继续尝试，补回缺失依赖后不需要手工删除数据。
- **失败同步逐步退避。** 正常首次同步仍即时/下个活跃刻执行；失败后间隔20、40、80、160、320、640、1200刻，此后最多每1200刻重试，成功移除状态。保留物品和奖励共用受保护的显式库存同步；没有变化则不请求同步。配方按玩家分别重试，管理员主动reload及新登录仍立即尝试最新内容。队列不因退避丢弃。失败环境同步恢复可能等待最多约60秒，这是避免持续失败吞噬服务器时间的权衡，正常同步不受影响。
- **奖励仍逐项保存。** 仅移除已经逐项保存之后的重复整批保存，保留每份奖励的独立提交与防重复。
- **清理二次失败不再阻止其他恢复步骤。** 掉落实体清理、替身移除、每个装备槽及乘骑关系分别尝试，汇总错误后抛出不会被可选转换包装器吞掉的AssertionError。不可安全回滚时仍明确停止不安全流程，不伪装成功或继续尝试转化。此处优先保证稳定性与数据一致性，不承诺撤销其他模组任意外部副作用。

本轮验证：Forge 139项、NeoForge 140项单元测试均通过，无失败/错误/跳过；两版独立开发服务器全套回归、`FAILURE_BOUNDARIES_OK`与新增`HOTFIX_COST_BOUNDARIES_OK`均通过。真实ItemStack.copy计数确认满背包128个有效条目恢复时无整包快照复制，释放一个槽位后准确补回一件并保留127条；128个未知条目连续40轮恢复原样保留，NeoForge无对应ERROR输出。故障同步同刻反复请求不再发送，延后到期且故障解除后清除待同步标记；清理二次失败仍恢复原实体装备并明确抛错。两版最终发布JAR在隔离正式加载器中到达主菜单、加载所有修改目标类并完成资源重载，生产JAR不含测试注入。两版玩法data/assets与hotfix.1逐字节一致。

本轮验证与两版安装包、源码快照保存在本地 `outputs/hotfix-cost-2026-10-25/`。性能结论来自真实调用计数与边界回归，不等同多人整合包TPS压测。此次未修改视觉代码，未重做雨雪场景/故意无效GLSL专项；此前记录不能当作本轮画面验证。AMD问题1与全部第三方组合仍未覆盖。
