# 1.1.1-hotfix.1：问题2稳定性边界修复候选

本候选对应用户定义的“问题2”（全模组稳定性边界扫描），Forge 1.20.1 与 NeoForge 1.21.1 分别实现。网络协议仍为13。Forge仅进入 `1.1hotfix` 分支，不合并main，不创建正式Release。

## 与问题1的范围区分

“问题1”是 AMD + Oculus 的原始 GLSL 编译兼容报告。本候选不改 vsh/fsh、fog 导入或变量命名，不声称修复该编译根因。这里修复的是其暴露的通用异常传播问题：天气着色器不可用时允许客户端继续加载并使用原版着色器；下一次资源重载可重新尝试。

## 正常体验约束

不修改伤害系数、掉率、配方、注册ID、既有存档键、技能时序、贴图、手记或前置依赖。正常路径继续应用同一暴击算法、天气效果、物品转换和奖励规则。新增日志限频，可选功能的错误不会逐帧刷屏。奖励物品仍即时进入背包，独立的显式同步移到下一活跃刻；通常菜单的正常同步也会发送该变更。

## 验证

本轮新增独立计算/配置回归，以及只在smoke source set中的实际游戏故障注入：背包插入后提交失败、未知物品恢复、同步异常后的奖励去重、装备入场被取消的转换回滚与正常转换精确掉落。故障注入Mixin不得进入发布JAR。

最终验证：Forge 138项、NeoForge 139项单元测试通过，均无失败/错误/跳过。两版独立开发服务器完整回归及 `FAILURE_BOUNDARIES_OK` 通过；两版实际发布JAR主菜单、全部修改目标类及资源重载通过；故意无效GLSL实际命中后仍完成启动和重载。NeoForge故障通过仅修改隔离测试JAR副本的着色器实现，候选包未修改。两版实际雨雪场景 `BLIGHTED_RAIN_CLIENT_OK`、`RAIN6_TOGGLE_NETWORK_OK` 通过，已核对本轮画面。安装包不含smoke/test类，玩法数据、贴图和原始GLSL内容一致性检查通过。

详细日志、故障测试说明及SHA-256保存在本地 `outputs/hotfix2-2026-10-25/VALIDATION.md`。AMD硬件组合未覆盖，不能据N卡验证宣称问题1已解决。

## 边界限制

本候选对本模组拥有的背包槽、保留记录、实体和显示资源建立恢复/降级路径，不承诺能撤销第三方在回调中执行的任意外部副作用。若核心回滚也被第三方拒绝或失败，将明确终止该不安全流程，而不是掩盖损坏继续重试。可选视觉钩子在冲突环境中降级时会失去对应附加效果，正常环境仍启用。
