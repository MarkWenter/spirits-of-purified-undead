# v0.46.2 · 莉莉手记 JEI 锻造显示修复

修复 JEI 中莉莉手记锻造不显示成品、点击成品无法查询来源的问题。两版加入专用锻造显示适配，明确提供白巫女手记、九种纯净灵药及莉莉手记成品；模板槽仍为空，不改变真实锻造条件或消耗。

原因是整合包使用的 JEI 15.20.0.116 默认按模板逐一计算锻造输出，空模板不会产生显示结果。开发环境较新的 JEI 已处理此情况，因此本次额外使用整合包同版 JEI 验证。问题与莉莉手记是否能装入追忆无直接关系。

## 兼容与交付

- Minecraft 1.20.1 / Forge 47.4.12 起，Java 17。
- Minecraft 1.21.1 / NeoForge 21.1.248，Java 21。
- JEI 仍为可选联动，无需替换为新的必需前置。
- 延续 0.46.0 的可选亡灵兼容、0.46.1 的 Forge 最低版本调整；联动名单见 [亡灵兼容说明](UNDEAD_COMPATIBILITY.md)。
- 配方、物品注册 ID、手记追忆数据、属性、美术与游戏内白巫女手记正文保持不变。

## 验证

- Forge 122 项、NeoForge 124 项单元测试通过；两版构建与独立服务端回归通过。
- Forge 实测 JEI 15.20.0.116（整合包同版）及 15.62.0.217；NeoForge 实测 JEI 19.57.0.450。
- 游戏内检查成品来源查询、真实显示布局、白巫女手记身份、空模板槽、九种纯净灵药用途，以及装有追忆的手记来源。
- 从 Minecraft 已加载配方核对 28 个非空输出来源，包含四件无垢护甲、白巫女手记和普通合成；另检查七种追忆、九种灵药酿造、12 条默认铸造配方与一条服务端自定义配方、两种燃料用途及同步刷新。未发现其他同类缺失。
- 独立服务端验证九种灵药的真实锻造、非法原料拒绝、铸造余料、亡灵兼容、追忆效果、进度及死亡保留。测试仅使用开发实例。
