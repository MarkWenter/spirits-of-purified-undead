# v0.55.0 · 配置管理、管理员指令与扩展接口

Forge 1.20.1 与 NeoForge 1.21.1 同步增加 `/purifiedundead` 指令。普通玩家可查看自己的获取记录；权限等级 2 的管理员可查询其他在线玩家、授予战士或契约、重置战士获取记录、回收玩家携带的战士饰品、设置护身符等级并重试待补发奖励。授予操作不会重复发放已领取奖励，满背包沿用挂起补发机制。

配置文件和已有键保持兼容，增加中文分组说明、89 个配置键的默认值／范围索引与服务端当前值查询。铸造配方新增严格重载：整份 JSON 校验成功后替换，失败保留当前运行配方，成功同步在线客户端和 JEI；TOML 仍建议两端同步后重启，不提供可能造成预测不一致的任意运行时改值。

公开 `dev.purifiedundead.api` v1：不可变进度快照、明确奖励发放、指定进度修改和保存后的进度变化事件。主线程与重入检查保护进度入口；自然获取和待补发同样可被扩展模组观察。现有数据标签及铸造配置继续作为其他模组兼容入口。

白巫女手记、既有平衡、注册 ID、存档格式、协议 10、必选前置及 Forge 最低 47.3.22 不变。本次不增加通用动态战士注册器。

两版完成构建、服务端完整回归及新增 `ADMIN_API_OK`；客户端使用真实指令重载并检查网络同步与 JEI 刷新（`ADMIN_CLIENT_SYNC_OK`），正式 JAR 另做独立启动检查（`PRODUCTION_STARTUP_OK`）。未操作正式存档。
