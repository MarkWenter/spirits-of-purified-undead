# v0.34.0 — 八件白巫女饰品

Minecraft 1.20.1 / Forge。客户端与服务器同时替换为 `purified_undead-0.34.0-dev.jar`，前置版本不变。配套的本地 Minecraft 1.21.1 / NeoForge 版本同步实现，最低 NeoForge 仍为 21.1.248。

## 饰品

装备古老民族之契后，放入白巫女饰品栏生效，默认提供三个栏位。每件占一栏，默认禁止重复佩戴同种饰品；背包内和装饰栏内不生效。八件均采用 64×64 透明像素贴图与 Minecraft 生成式物品模型。

| 饰品 | 效果 | 获取 |
| --- | --- | --- |
| 血染的丝带 | 经验点获取量 +25%，保留零碎经验的小数余量 | 四个红色羊毛围绕中心怨念污秽，十字形合成 |
| 古龙爪吊坠 | 远程伤害 +135%，即原来的 2.35 倍 | 远古残骸和四个怨念污秽，无序合成 |
| 风化的战士项链 | 击杀怪物恢复 35% 已损失生命值 | 铁剑、铁镐、铁斧、普通饮用型治疗 II 药水、怨念污秽，无序合成 |
| 脏污的银念珠 | 最大生命值 +5% | 三个铁粒、两个污秽碎片，固定形状合成 |
| 白巫女的雕像 | 致命伤害触发不死图腾效果，120 秒冷却，不消耗饰品 | 指定战利品箱 |
| 秽鬼之指 | 造成伤害 +25% | 八个怨念污秽围绕中心腐肉合成 |
| 王之盾的徽章 | 最大生命值 +25% | 五个铁块、一个怨念污秽，固定形状合成 |
| 白巫女的耳环 | 致命伤害触发不死图腾效果，600 秒冷却，不消耗饰品 | 指定战利品箱，概率为雕像的两倍 |

固定配方（空格位置为空）：

```text
血染的丝带       脏污的银念珠      秽鬼之指        王之盾的徽章
  羊毛          铁粒 空 铁粒      怨 怨 怨        铁块 空 铁块
羊毛 怨 羊毛    碎片 铁粒 碎片    怨 腐肉 怨      铁块 怨 铁块
  羊毛                           怨 怨 怨          铁块

怨 = 怨念污秽；碎片 = 污秽碎片；羊毛 = 红色羊毛。
```

配方同步进入原版配方书，获得相应污秽材料后解锁。治疗 I、水瓶、其他药水和喷溅药水不能替代治疗 II。

## 宝箱概率

| 主世界战利品来源 | 雕像 | 耳环 |
| --- | ---: | ---: |
| 废弃矿道箱子矿车 | 2% | 4% |
| 要塞走廊、交叉口、图书馆箱子 | 3% | 6% |
| 远古城市箱子，包括冰箱战利品箱 | 5% | 10% |

每次战利品生成分别独立抽取，可能同时出现；不替换原版或其他模组的战利品。已经打开、已经生成物品的旧箱子不会补发。数据包可覆盖 `purified_undead: white_witch_*` 对应全局战利品修改器中的 `statue_chance`，耳环始终按该值的两倍抽取。

## 交互规则

- 两件生命饰品的百分比相加，同时装备为 +30%；卸下后及时移除属性，不凭空回血。
- 古龙爪识别投射物实体或 `minecraft:is_projectile` 伤害标签；秽鬼之指与古龙爪同时生效时，远程倍率为 1.25 × 2.35。协同攻击从未加饰品倍率的基础伤害派生，再各自加成一次，避免重复放大。
- 项链识别实现原版 `Enemy` 接口的怪物，包含采用该接口的模组怪物；不会通过击杀普通动物或玩家触发回血。
- 复活冷却保存在玩家数据中，跨摘戴、换物品、死亡重生、重新登录保留，按世界游戏刻计时。两件独立冷却，同时可用时优先雕像；雕像冷却期间可由耳环救命。同种多个饰品不会绕过冷却。
- 复活效果为 1 点生命、生命恢复 II 45 秒、伤害吸收 II 5 秒、防火 I 40 秒，并移除原有药水效果、播放原版图腾表现。手持原版图腾优先消耗；虚空及绕过无敌的致死伤害保持原版无法救活规则。
- 现有 `[whiteWitchRelics]` 配置可禁用效果、允许重复饰品、统一调整效果强度及冷却倍率。重复饰品的数值效果仅在开启重复装备时叠加。

## 验证

Forge 114 项、NeoForge 116 项自动化测试通过。开发专用服务端检查覆盖真实配方注册及治疗 II 匹配、经验事件、Curios 佩戴属性、伤害与回血、两种独立复活冷却和虚空例外；实际战利品生成验证目标箱表可掉落饰品，普通地牢不受影响。客户端启动及资源加载检查通过。测试代码不进入发行 JAR。
