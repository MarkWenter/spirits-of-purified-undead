# 0.37.0：净化更新第一阶段与光点修复

古老民族之契净化怨念污秽时，现在获得 4 个纯净结晶。满级后仍可消耗材料，不再提高护身符等级。加入净化弧钢、净化弧钢锻造模板以及纯净灵药的普通、延长、强化和瓶型变种。规则见 [净化更新记录](purification-update/README.md)。模板与弧钢暂为材料，后续锻造用途尚未定义。白巫女手记保持不变。

光点改为客户端管理器独立推进，不再依赖所在区块是否更新实体；采用零尺寸碰撞箱，禁用拾取、碰撞、推动和流体/传送门/虚空实体逻辑。修正小包围盒导致的距离裁剪，移除因玩家隐身而删除光点的逻辑；意外被清理时在下一个客户端刻恢复并尽量保留位置，传送时重置插值，避免横跨画面的光点轨迹。光点仍受正常墙面遮挡，进入墙体期间可能看不到，但不会被墙阻挡或留在墙内。

保留最多 16 个附近光点、4 个动态光源和少量粒子的限制。可选 RyoamicLights 与 Oculus/Iris 联动保持可用，无新增必需前置。

NeoForge 1.21.1 成品：`purified_undead-1.21.1-0.37.0-neoforge-dev.jar`，最低 NeoForge 21.1.248 不变。

用对应成品替换旧版主模组 JAR，客户端与服务端同时更新，原有前置不变。
