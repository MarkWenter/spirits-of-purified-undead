# v0.46.1 · Forge 47.4.12 兼容要求调整

目标为用户更正后的 **Minecraft 1.20.1 / Forge 47.4.12**，不是 47.0.12。

原模组在 `mods.toml` 中要求 Forge `[47.4.23,48)`，会直接阻止 47.4.12 加载。本次将其改为 `[47.4.12,48)`，同时把实际编译基线改成 47.4.12 并重新生成 JAR，避免仅修改旧 JAR 的版本声明。

未发现需要改动玩法源码的接口障碍。Curios 5.14.1、GeckoLib 4.8.4、Patchouli 1.20.1-85、Apothic Attributes 1.3.7、Placebo 8.6.3 保持原版本；其加载声明均允许 47.4.12，并随本次开发环境完成运行验证。

## 验证

- Forge 47.4.12 实际编译与构建成功，122 项单元测试通过。
- 独立服务端完整回归通过：亡灵联动、石板更新、铸造余料与漏斗、莉莉手记、净化、遗物、进度、极限保命、费林生命周期等均有对应游戏内通过标记。
- 安装 JEI 的实际客户端通过 `FOUNDRY_CLIENT_OK` 与 `SLATE_CLIENT_OK`：真实批量加工、服务端进度、方块亮起／待机、物品模型、主手打开手记、八槽同步、挂墙及释放。JEI 在世界内正常初始化。
- 发布 JAR 不含测试类或测试实体标签；既有物品、美术、白巫女手记和配方资源未改变。

本轮没有把完整 261 模组整合包一起运行，不代表其他模组自身的加载器要求也已改变。适配要求为 Forge 47.4.12 起的 47.x；本轮实际运行基线为 47.4.12，之前的 47.4.23 回归记录保留。

只更新 Forge 1.20.1 成品为 `purified_undead-0.46.1-dev.jar`；NeoForge 1.21.1 工程及成品保持 0.46.0。更新时替换旧的本模组 JAR，客户端与服务器均应使用新版。
