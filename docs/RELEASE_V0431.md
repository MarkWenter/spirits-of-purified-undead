# v0.43.1 极限模式秽鬼化保护

Minecraft 1.20.1 Forge 与 1.21.1 NeoForge 同步实现。

- 极限模式玩家处于秽鬼化时，致命伤害会触发图腾式保命，消耗秽鬼化并发放古老民族之契，无需携带不死图腾。
- 保留 1 点生命，清除原有效果，获得生命恢复 II 45 秒、伤害吸收 II 5 秒、抗火 40 秒，并播放原版图腾效果。
- 手持真实图腾或本模组白巫女遗物先触发保命时，同样完成契约获取。真实图腾仍正常消耗，遗物仍进入原有冷却。
- 契约保持一次性发放；满背包时记录待领取奖励，腾出空间后补发，并正常解锁“隐秘之力”。再次饮药可再次保命，但不会重复发放契约。
- 普通模式的死亡复活流程不变；关闭契约获取配置时不启用此替代流程。

验证：两版完整构建及服务端致命伤害测试，覆盖普通模式、无药效、重复奖励、真实图腾、遗物保命、配置关闭、满背包补发和进度授予。
