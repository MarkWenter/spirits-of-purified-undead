# v0.50.0 · 灵灾精魂掉落与剑气手感修正

Forge 1.20.1 / NeoForge 1.21.1 同步更新，客户端与服务端都需升级（协议 9）。

- 修复秽鬼之守护虽然可附魔精魂劫掠、缚灵，但未被 Malum 识别为可收割精魂武器的问题。接入两版各自的原生武器标签，剑刃与剑气击杀均交由 Malum 正常处理。
- 不复制精魂掉落算法、不额外生成重复掉落，不改变 Malum 对目标精魂数据、无魂状态及刷怪笼来源的限制。未安装 Malum 时不增加必选前置。
- 剑气速度由每刻 1.75 格调为 1 格，七格射程耗时七刻（正常 20 TPS 约 0.35 秒）。保留客户端即时显示。
- 视觉线性尺寸扩大 25%，命中检测扩张值从 0.8 格改为 1.0 格；继续限制七格最远距离、禁止穿墙、每目标每发一次伤害。
- 近战伤害归属、箭矢伤害倍率、协同暴击和四名战士联动保持不变。

原因和验证详见 [0.50.0 记录](purification-update/GUARDIAN_050.md)。Forge 最低版本仍为 47.3.22，白巫女手记未改。
