# 0.56.0 全项目规范与兼容性审查

## 范围与不变项

两版实际工程的业务源码、开发回归、注册与元数据、配置读取、网络、物品/容器存储、实体与战斗、客户端、可选联动、Mixin、依赖和打包流程。保留原玩法、配方、伤害系数、注册 ID、存档格式、网络协议及白巫女手记内容。Forge 最低 47.3.22 不变。

## 已修复

|位置|确认的风险|处理|
|战利品、伤害标签和击杀条件的五个注入器|Redirect 独占调用点，其他模组修改同一点可能争用；原来的击杀转发还绕过了调用链|改为 WrapOperation；每层传递 original，伤害身份仍只在条件判断作用域内生效；增加独立第二包装器并存回归|
|Patchouli 手记识别|每次识别重复查类、方法、字段；接口变动可能抛出异常|延迟缓存访问对象；接口失配只记录一次并停止该桥接，避免频繁重试；正常书本识别不变|
|移动设置同步|非有限值或超出已有配置范围的值可能进入客户端速度计算|以既有 0–10 范围校验两项数值，整包非法则保留原值|
|移动动作请求|重复无效请求不断触发装备查询和传送纠正|每玩家每服务端 tick 最多处理八条，足够正常按下/松开顺序；下一 tick 恢复，退出/停服清理，不新增每刻扫描|
|扩展进度事件|故障扩展可反复输出大堆栈；链接错误可阻断已完成的奖励调用|仅扩展通知边界隔离 RuntimeException/LinkageError，保存结果不回滚；自身诊断每分钟最多一次并统计省略次数；不吞掉虚拟机致命错误|
|Forge 追忆身份查询|八个槽各自遍历 NBT 列表|一次遍历压入八个身份字节，不反序列化物品，不额外建缓存，保持最后重复槽覆盖、无效/空物品清空和超大列表保护语义|
|工程规范|大量压缩为单行的生产和测试代码影响复核|统一两版 Java 格式，格式化单独核对非注释代码标记；增加固定版本/散列校验的格式脚本和 EditorConfig|

## 已审查而保留

- 网络在主线程处理、按方向注册；协同/剑气请求传意图，伤害和目标由服务端确定。正常战斗不新增网络往返。
- 铸造配方 4096 条、文件 8 MiB、同步字节上限和严格重载先验证后替换；闲置方块已有快速返回；本次不改变下槽余料规则。
- Forge 方块能力失效/重建、NeoForge 原生能力注册，容器失效与手记锁定物品检查保留。
- JEI 使用可选桥接，运行时释放时清空引用，配方刷新去重；服务端不加载界面类。
- 战斗、战利品、海尼尔/星月条件的作用域在 finally 恢复；保留防递归与玩家击杀归属。实际伤害不变。
- 可选灵灾、星月、谜之遗物、动态光源桥接已有缓存、类型/装备短路及失配退出，不改成每实体或每刻反射。
- 战斗玩家状态已有退出/停服清理；动态光点渲染沿用当前实现，本次不改变透明物体绘制顺序。
- 编译基线保留旧 Forge 所需接口；加载器自身的弃用提示不通过盲目升级前置消除。

## 代码来源与许可

本地比对两版 374 个生产 Java 文件与 3891 个可查证参考源码文件（Patchouli 源码包和历史联动核查资料）。剔除注释/导入后，以 80 个连续标记、参考步长 40 做候选重复片段检测，未找到候选匹配。结合生产包命名空间检查，未发现将参考模组实现类直接打入本体的情况。这不是对互联网全部代码的原创性证明，也不是逐行人工阅读全部依赖。

MixinExtras 为官方 MIT 许可基础库，Forge 通过 Jar-in-Jar 附带未经修改的 0.5.3，NeoForge 使用加载器已有版本；不复制其源代码、不增加玩家安装步骤。原有五个外部前置不变。许可见 licenses/MIXINEXTRAS_LICENSE.txt。Patchouli 衍生 GUI 纹理继续按已有单独声明处理，不能将素材也宣称为完全原创。

官方依据：[MixinExtras 安装](https://github.com/LlamaLad7/MixinExtras)、[WrapOperation 串联说明](https://github.com/LlamaLad7/MixinExtras/wiki/WrapOperation)、[格式工具](https://github.com/google/google-java-format)。
