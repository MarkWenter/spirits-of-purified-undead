# v0.45.0 · 石板更新第二部分

新增石板、解语密文、七种铸造石板、八种秽鬼追忆及闪耀的守护宝具，共 19 件物品。

纯化铸造器接入两种指定燃料、20 秒批量加工、五种原版资源配方和七种保留战士饰品的石板配方。成品超过下槽容量时只加工可容纳数量，余料内部保存。配方可通过 JSON 配置自定义，包括是否消耗上槽模板。

莉莉手记可主手使用打开八槽环形界面。佩戴时启用装入的追忆；格洛特、伊莱恩与费林的战士强化沿用原有效果前提。法腾额外 +2 抢夺，海尼尔四种异常各自独立 25%、持续 5 秒、I 级。费林追忆按玩家收集记录发放一次，满背包补发。

Forge 1.20.1 与 NeoForge 1.21.1 同步实现，新增物品贴图为 16×16。白巫女手记正文与既有资源保持不变。
