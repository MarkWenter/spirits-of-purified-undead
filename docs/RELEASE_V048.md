# v0.48.0 · 秽鬼之守护强化

Forge 1.20.1 与 NeoForge 1.21.1 同步增加剑气、主手护甲和可选附魔兼容。

- 主手持有时增加 10 点护甲，通过装备属性实现，卸下自动撤销，不使用每刻检测。
- 每次攻击键挥剑都可发射剑气，包括未点中实体的空挥。沿挥剑时准星方向前进，最远 3 格，约 6 刻结束；不穿实心墙，每发对每个目标最多结算一次。
- 剑气基础倍率为近战伤害的 120%，按原版蓄力比例缩放；连续空挥同样需要蓄力。保留挥剑时的下落、疾跑和方向，使用玩家近战伤害事件，接受伤害增幅。
- 剑刃与剑气可分别伤害同一目标。剑气命中可以触发/续接费林协同攻击，并触发伊莱恩魔弹、海尼尔标记、格洛特下劈眩晕等近战效果；保留各效果原有概率、装备条件、冷却和同刻去重。
- 剑气额外使用费林协同攻击的暴击判定；支持费林追忆的协同伤害增幅。复用费林第一段刀光的网格及纹理，随机改变 0–180° 斩击倾角，飞行方向不随机偏转。
- 神化、星月附魔按下界合金剑可接受的非诅咒附魔规则兼容；灵灾额外查询实际注册镰刀的适用附魔。保留互斥、等级与原有自动经验修补/去诅咒规则。不加入新的必选前置。
- Forge 兼容星月所依赖伤害追踪库的事件顺序：伤害完全被吸收生命挡住时，不再错误触发费林吸血。
