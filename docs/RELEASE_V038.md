# 0.38.0 — 净化配方与大型生物兼容修复

- 纯净灵药统一使用不带额外颜色标签的标准药水数据，物品显示按药水身份着为天蓝色。旧瓶子继续可以酿造；完成酿造后清理旧颜色字段。普通药水颜色仍按原版数据计算。
- NeoForge 改用原生药水混合配方，避免自定义配方描述与药水枚举形成两套入口。Forge 保留准确匹配药水身份的酿造描述。两版 JEI 均验证 15 条唯一有效配方，展示输入均可产生展示输出。
- 协同攻击新增服务端近战观察：针对自行实现受伤、不发出完整 LivingHurt/LivingDamage 回调的生物，在同刻末确认实际生命减少后补触发。多部件攻击识别本体，并朝命中的部件/碰撞箱表面出刀，而非远处的本体中心。
- 免疫、格挡未扣血、取消的攻击不会走补触发；原有同刻去重、冷却与连段规则不变。观察仅保存到本刻末，不扫描全世界生物，不新增网络包。
- 纯净结晶、净化弧钢及锻造模板改为浅灰、柔和蓝与暖金配色；模板增加不对称破损石质感。
- 白巫女手记不更新。独立内容记录见 [净化更新](purification-update/README.md)。

验证：两版构建和单元测试；独立服务端的全部净化酿造/合成/消耗交易检查；模拟大体型自定义受伤生物、免疫生物及末影龙多部件识别；真实 JEI 客户端配方枚举、实际酿造比对及颜色检查。JEI 为本地测试可选项，不是前置，不打包。

范围说明：未取得用户整合包里出现问题的具体怪物清单，故本次验证覆盖了通用事件缺失和多部件情况，不能宣称逐一测试所有第三方 Boss。
