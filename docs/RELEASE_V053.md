# v0.53.0 · 物品文案与等量净化

按用户编辑表的 25 项要求调整 Forge 1.20.1 与 NeoForge 1.21.1 的玩家可见物品文字。

- 怨念污秽净化改为消耗 N 个、产出 N 个纯净结晶。N 沿用 `purified_undead-common.toml` 中 `talisman.blightedSpiritsPerLevel`，默认 4，范围 1–64。悬停文字与净化成功提示同步显示数量。
- 护身符满级仍可净化；按要求删去这项文字说明，不删除功能。满背包时仍掉落无法放入的结晶。创造模式保留不扣材料的原有行为，产出采用配置数量。
- 莉莉手记新增“目前属性”行，显示当前佩戴时手记自身提供的暴击率、幸运加值，不混入其他装备或基础属性；卸下后显示 0。背景介绍改为青色，放到物品描述末尾。
- 应用战士、莲花、保命遗物与追忆的指定文案；删除秽鬼之守护的剑气说明行，保留英文句子及原有属性信息。

未改写的条目保留原文。战斗、剑气、追忆效果、护身符成长、配方和注册 ID 不变。白巫女手记正文不更新；前置、协议 10 和 Forge 最低 47.3.22 不变。
