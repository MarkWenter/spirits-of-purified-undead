# 涤净亡魂 1.1 正式版 — 污秽之雨更新

支持 Minecraft 1.20.1 / Forge 与 Minecraft 1.21.1 / NeoForge。本次正式版汇总污秽之雨各阶段内容及修复，相较 1.0 新增以下内容。

## 天气与世界
- 加入主世界事件“污秽之雨”，包含预警文字、预警音效、灰暗降水与红色侵蚀表现；寒冷地区呈现污秽之雪。
- 默认事件有15秒预警，持续5～10分钟，结束后进入15分钟冷却。
- 玩家暴露于污秽降水时获得力量、急迫和秽鬼化；生物可能受伤或转化。屋顶可提供遮蔽，村民会尝试寻找可达的避雨地点。
- 亡灵生物免受污秽雨伤害，幻翼除外；秽鬼生物不会在阳光下燃烧。保留宠物归属保护与可配置的雨伤免疫。
- 创建世界时可在游戏规则中选择“是否启用永雨”。关闭后使用正常天气，新世界玩家首次进入时获得一个秽雨纹章；普通雨天仍可能自然发生污秽之雨。
- 新增静雨信标：放在紫水晶块上并接通红石即可恢复正常天气、阻止自然污秽之雨并暂停冷却。区块卸载后保留已确认的激活状态，激活时明显发光。
- 新增秽雨纹章：长按主动引发污秽之雨，无视冷却与静雨信标。共20点耐久，每次使用消耗1点；强制事件结束后恢复信标的抑雨状态。

## 秽鬼生物
- 新增秽鬼僵尸、骷髅、溺尸、尸壳、流浪者、村民、掠夺者、卫道士、女巫、猪、牛、羊、鸡、马、驴、蜘蛛；1.21.1额外加入秽鬼沼骸。
- 为新生物制作红眼、暗色裂纹与暗红侵蚀纹贴图，保留原生物辨识度，支持相应幼年、衣服和外观变体。
- 一般生物暴露累计达到10秒后转化；村民和鸡在污秽雨伤害致死时转化。转化处理装备掉落、拾取与骑乘分离。
- 僵尸家族具有更高生命与伤害、更低移速；骷髅家族具有更高生命与伤害、更低移速和射击频率。
- 秽鬼溺尸攻击附加缓慢，尸壳额外增加伤害；流浪者与沼骸保留缓慢箭、中毒箭。
- 秽鬼村民为敌对生物，可手持普通瓶装纯净灵药对其使用，等待治愈为普通村民。
- 秽鬼蜘蛛有更高生命、更低移速，攻击有10%概率施加10秒虚弱。
- 秽鬼猪与牛额外掉落腐肉；秽鬼羊剪毛仅掉落红色羊毛。
- 添加秽鬼专属实体标签、对应刷怪蛋及独立创造模式物品栏。

## 新物品与配方
- 墓穴泞尘：秽鬼蜘蛛掉落的材料，数量受抢夺影响。
- 污秽红宝石：秽鬼掠夺者、卫道士及国王的概率掉落材料。
- 秽鬼女巫新增秽鬼灵药概率掉落。
- 污秽肉：秽鬼家畜额外掉落，可食用但附带短暂中毒与虚弱；可烤制成熟污秽肉，获得更高回复且无负面效果。
- 悬崖村的少年：可反复使用的投掷物，在落点造成范围伤害和眩晕；10点耐久，耗尽不消失，在物品栏中每30秒恢复1点。支持力量、冲击、火矢等适用附魔，不支持无限。
- 无头的骑士：新增盾牌，持有时提供5点护甲，支持盾牌附魔；采用外侧纹章、内侧背板与握柄的盾牌模型。
- 静雨信标可在纯化铸造器中以信标和闪耀的守护宝具制作，守护宝具不消耗。
- 洁白莲花、猩红莲花可作为植物放置；保留原手持图标和食用功能。
- 补充合成、烹饪、铸造配方与JEI显示。

## 饰品、手记与操作
- 伊莱恩：副手持疲惫的心，累计击杀溺尸、秽鬼溺尸或秽鬼女巫，默认共3只，可混合计数。
- 法腾：治愈僵尸村民或秽鬼村民均可满足对应获取事件。
- 海尼尔：在身负至少3种负面效果时击杀任意秽鬼生物；普通僵尸不再满足目标条件。
- 新增独立饰品配置文件 purified_undead-accessories.toml，包含81项数值设置；自动继承旧配置并保留备份。追忆石板仍使用原独立配置。
- 新增“费林协同攻击”和“二段跳与空中冲刺”两个开关键，默认均未绑定；技能默认保持开启，需要在控制设置中自行绑定后切换。
- 更新白巫女手记，加入污秽之雨、材料与装备教程，“其他内容”保留在目录最后。

## 修复与优化
- 修复强制污秽雨结束后静雨信标未恢复抑雨状态。
- 修复污秽之雪大面积红色闪烁，优化雨落地粒子表现。
- 修复掠夺者失去弩后无法攻击，并改善盾牌手持、格挡姿势及透明边框问题。
- 扩大雨伤对第三方生物的支持，修复妖精女仆被旧筛选范围排除的问题；继续尊重免疫、归属保护及其他模组正常取消伤害的行为。
- 优化村民避雨寻路、投掷物耐久恢复同步和信标状态处理；加强配方迁移与投掷伤害数据校验。

## 安装与升级
- 请按游戏版本选择 Forge 或 NeoForge 文件，替换旧版模组JAR，勿同时安装多个版本。客户端与服务器须一起升级，本版网络协议为13。
- 必需前置：Curios API、GeckoLib、Patchouli。建议安装 Apothic Attributes 及其前置 Placebo，以获得完整属性效果。
- Forge需要Java 17，NeoForge需要Java 21。升级已有世界前建议备份存档和配置。
- 本版延续既有注册ID和存档数据。第三方整合包、光影及自定义生物归属系统组合无法穷尽验证。
