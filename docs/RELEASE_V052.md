# v0.52.0 · 追忆增强与剑气射程

Forge 1.20.1 与 NeoForge 1.21.1 同步；客户端与服务端需一起更新（协议 10）。Forge 最低版本仍为 47.3.22，前置依赖不变。

- 秽鬼之守护剑气最远距离 7 → 15 格；速度、宽度、伤害倍率与即时预测不变。
- 法腾追忆取消额外抢夺 II，改为标准怪物战利品随机概率判定翻倍、最高 100%。原附魔加成照常参与，不重复生成必掉物品；本模组污秽碎片掉率也支持。
- 海尼尔追忆为掉落与进度条件补充凋零、原版中毒（魔法）、燃烧、冰冻的伤害标签。实际伤害来源、伤害次数、护甲、抗性、免疫计算保持原样。
- 经确认，额外兼容星月遗物虚无刻蚀板的深渊击杀条件，仅限海尼尔追忆击杀监守者时；其他获取前提和掉率保留。
- 狼追忆：贴墙悬挂后松开并再次按跳跃，可向上攀跳；客户端当刻预测，服务端检查墙面、装备、最近悬挂及重复请求。每 5 秒恢复 4 点饥饿值和 4 点饱和度，遵守原版上限。
- 姐妹追忆：跳跃高度增加约 0.5 格，免疫摔落伤害；兼容已有跳跃初速度和重力变化。
- 费林追忆：原有协同攻击增伤由 50% 提高到 150%。配置中的旧默认值迁移，其他自定义倍率保留。

光点透明层遮挡本次按用户允许的范围暂缓：原发光透明渲染不写深度；简单改为写深度会使光晕产生圆形遮挡边界。已撤销该实验改动，完整方案需处理透明排序与光影管线。
