# v0.32.0 · 秽鬼外观与战斗更新

适用于 Minecraft 1.20.1 / Forge 47.4.23，依赖与初版一致。

- 秽鬼傀儡、秽鬼国王新增黑红腐化纹路和红眼，沿用原版模型及 UV。
- 秽鬼傀儡最大生命值提高至 200，保留此前加快的近战攻击。
- 秽鬼国王最大生命值提高至 100，尖刺施法间隔由 100 刻缩短至 50 刻；恼鬼召唤不变。
- 普通铁傀儡与唤魔者不受影响。
- 旧版生物按剩余生命比例迁移；旧 NBT 国王转换为独立实体并获得新 UUID。

构建成功，105 项自动测试通过。贴图尺寸、透明区域和 JAR 资源校验通过；本次改动尚未进行游戏内完整验证。更新前建议备份世界。

安装：将旧版本模组 JAR 替换为 purified_undead-0.32.0-dev.jar；不要同时安装两个版本。客户端与服务器均需更新。
