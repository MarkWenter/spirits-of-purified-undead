# 费林更新第一部分：普通协同剑气

候选版本：Forge 1.20.1 / NeoForge 1.21.1，均为 **1.2.0-ferin.1**。网络协议 **14**，进度 API v1 不变。此候选尚未游戏验收；不表示正式发布。

## 已实现范围

- 所有普通费林协同剑气从服务端维护的光点逻辑位置发射。光点沿用左右、移动拖尾与平滑运动规则；服务端取所在方块中心作为离散发射锚点，客户端保留连续光点，所以二者可能有小幅空间差异。
- 以光点到实际受击碰撞箱点的三维连线发射，支持高低差、大型/多部件目标以及秽鬼之守护剑气触发的协同。没有采用固定偏折角度。
- 每段独立保存发射时伤害、暴击、目标身份、飞行状态与已命中集合。后续连段不截断旧段，命中沿用原伤害公式、玩家归属、队友/宠物/PVP过滤、穿墙、单段单目标去重及海尼尔标记处理。秽鬼之守护自身剑气未修改。
- 射程预算为发射时锚点到目标点距离 d 加 4 格（这是枢轴的移动路程；刀光本身仍有原有尺寸）。速度为 max(最低速度, d/max(1,到达刻数))。五段共用同一速度规则；0 刻按下一个服务器刻处理。正常20 TPS下目标点的名义到达时间不超过3秒，卡顿不保证现实秒数。
- 每刻有界转向，只追踪发射时记录的同一实体。追踪不保证命中移动目标，也不延长初始路程和寿命。目标死亡、离开当前维度或不可查时，该发直线走完剩余预算，不另选目标。
- 没有新命中的后续段优先追踪上段目标；旧目标失效时，从新光点锚点沿玩家当前完整视线发射。无目标的初始瞄准距离沿用该段旧 reach，再加4格预算。
- 整片扇形/环形剑气采用连续三角面扫掠，替换原来五个时间抽样。命中厚度从0.30扩大为0.50格，即额外0.20格容差；刀光网格、半径、贴图、色彩不因碰撞容差放大。
- 客户端使用同步的方块坐标＋局部偏移、方向、年龄与速度做最多2刻的视觉外推；每次服务端同步纠正。无客户端伤害授权，无新增可伪造目标/伤害的请求包；实体身份负责区分各段，重复同步不生成第二发。初次发射仍须等待服务端确认，不能承诺任意高延迟下零延迟。
- 死亡、换维、注销、失去契约、旁观、关闭费林技能会清理飞行；注销取消活动连段但保留召唤冷却。飞行不写入存档，不在重登后补发旧伤害；旧存档键和版本格式保留。

本部分不实现骑士寂夜、女仆绑定/切片/虚影、女仆增伤、好感度、魂符或自定义骨骼动画。

## 配置与边界

配置文件 `config/purified_undead-accessories.toml`，`[ferin]`：

| 键 | 默认 | 可用范围 | 含义 |
| --- | --- | --- | --- |
| flightMinimumSpeed | 1.0 | 0.25—64 | 最低格/刻；远距离仍可按到达时间提高速度 |
| flightArrivalTicks | 60 | 0—60 | 目标点的名义最迟到达时间，0按1刻处理 |
| flightTurnDegrees | 6.0 | 0—30 | 每刻最大转向角，0关闭追踪转向 |

修改后重启，所有客户端与服务端使用同一候选版本。最远异常输入安全边界4096格，超过该范围不生成这次剑气；不强制加载区块，不跨维度索敌。额外4格可使消失时间稍晚于名义到达时间；默认最多64刻，最低速度配置0.25时绝对上限76刻。每玩家最多80发，正常连段远低于此上限。有限路程、寿命、去重集合生命周期与实体租约防止永久追踪及残留。

长对角路径按16格切分实体查询范围，避免扫描巨大立方体；同刻候选去重、扫掠包围盒预筛选后才作精确判定。光点每玩家每刻仅常数次向量运算，无全世界搜索；客户端每帧只计算一次坐标基，避免每个顶点重建基向量。现有稳定性hotfix边界保留。

## 架构

`FerinFlightMotion`负责纯飞行/三维基，`FerinWispMotion`提供双端共用光点运动，`FerinWispAnchor`持有服务端离散锚点，`FerinSlashFlight`持有独立发射上下文。原`FerinCombatEvents`仍是唯一事件入口；实际伤害继续走原计算链。旧`FerinPlayerState`序列化、纯轨迹接口和`client/WispMotion`兼容入口保留，不将第三方模组依赖接入本部分。

实体同步结构变化，两版协议从13升到14，旧客户端不能混连本候选。不同加载器API已分别适配，NeoForge源码仍不提交到根Forge仓库。
