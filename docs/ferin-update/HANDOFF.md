## 本轮修复与兼容性

- 新绑定只从物品接收身份信息。服务端用三个 UUID 建立账本记录，不接收来自物品的切片、死亡标记、击杀或待结算好感。存档仍使用原有数据名和字段，旧记录可继续读取。升级不会主动重建已有世界中的绑定。
- Forge 检查未绑定饰品时不再创建空标签。NeoForge 逐刻匹配三个身份字段，省去复制整个物品自定义数据。YSM 外观变量最多检查 64 项，避免大量无效条目拖长采样。保留当前和历史两份切片，显示物品仅发送白名单外观字段。
- 正常连段保留原有伤害顺序。若女仆加成与本段暴击相乘后溢出，则回到同一目标的普通费林暴击伤害，进入伤害事件前继续检查有限性。光点收到非有限位置或朝向时丢弃当次采样，下一次有效输入能恢复。
- 服务端每玩家刻复用契约资格和连段计时参数。飞行走廊没有合法候选时跳过 181 份精细扫掠，有候选时仍使用全段轨迹。客户端复用同一刀光截面的几何采样，避免同位置的每个顶点重复求切线。
- 酒狐骨骼的独立短轨道抵达末帧后保持其姿态。可选女仆渲染接口发生链接错误时，该渲染器记录一次并继续绘制普通刀光，资源重载后新渲染器可重新接入。

## 后续维护

遇到佩戴、魂符或死亡状态异常，先检查服务端玩家、饰品、绑定批次和女仆身份，再检查账本中的当前切片。遇到某款皮肤动作异常，先区分原生 Gecko、已有切片映射的 YSM 变体和原生动作回退，检查客户端显示配置、模型资源与握剑骨。剑面沿切线的问题可通过 `FerinSwordFrameTest` 隔离，动画收尾可通过 `FerinComboCutTest` 隔离。

合并前在待合并的实际主线重跑两版独服测试，分别装载和移除车万女仆，并核对游戏内结束标记。涉及附属兼容时检查 `spirits_of_expand` 的进度 API 和污秽之雨桥接。世界机制证据索引仍以旧版为基线；本轮查读了实际实现，没有刷新其他对话正在维护的指纹。

### 检查边界

本轮检查覆盖费林分支改动触及的生产路径及其主项目调用方。Codex Security 的差异扫描器未能解析本机工作树的 HEAD，未生成自动扫描报告。上述安全结论来自双版源码审阅、定向断言和隔离实例回归。

多人高密度战斗的 TPS、不同显卡和完整第三方整合包仍需现场数据。对完全绕过原版伤害事件的 Boss，既有补触发依靠同刻血量差，多来源同刻扣血的精确归因仍有限制。实验性女仆伤害归属沿用原有兼容边界。附属 0.2.0 本轮验证了与原样发布包共同启动及重载；附属的独立玩法未在本轮重复全测。
