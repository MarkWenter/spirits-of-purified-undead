# 费林更新第二部分 · 骑士寂夜

对应 Forge 1.20.1 与 NeoForge 1.21.1 的 1.2.0-ferin.5，联动基线为车万女仆 1.5.3。加载女仆时注册单件饰品及其女仆槽行为。祭坛无序投入纯净触碰、神龛、下界合金锭、钻石、金锭、铁锭各一个，消耗 0.1 P 点。

玩家蹲下使用切换绑定，再将饰品放入自己女仆的饰品槽。遗失时执行 `/purifiedundead knight_nocturne unbind`。玩家 UUID 对应的世界存档记录保存物品身份和绑定批次，使离线、跨维度和魂符内的旧物品都受解绑约束。主动卸下清空女仆绑定、切片和该绑定的击杀进度。死亡锁定阻止新剑气，复活且仍佩戴时恢复。

饰品配置位于 `config/purified_undead-accessories.toml` 的 `knightNocturne` 节。默认每 40 刻采样女仆的攻击基础值、三类属性修饰汇总、好感度和有限的模型及背包外观字段。魂符保留最近一次有效切片。异常使采样暂停，取下重戴后可重新采样。

先把本段暴击前、目标防御前的协同伤害并入女仆基础攻击，再计算加法、基础乘数与独立乘数，最后应用本段费林暴击。默认伤害归属玩家，每 20 次协同怪物击杀累计 1 点好感度，待绑定女仆活动时写回。实验性女仆来源在同维度能解析到存活女仆时将其作为直接来源，玩家仍是致伤者。其他模组可能对此作不同解释。

模型源文件见同目录 knight_nocturne.bbmodel。GUI 使用 32×32 精灵图，1.2.0-ferin.6 手持模型使用独立 64×64 材质和 29 个部件，分别表现银刃、宝石护手、握柄吊环和两股绕剑灵体。女仆虚影留待后续更新。
