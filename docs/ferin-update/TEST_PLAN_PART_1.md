# 费林更新第一部分：外部测试清单

测试对象：`1.2.0-ferin.1`，Forge 1.20.1 与 NeoForge 1.21.1 **分别测试**。当前状态：编译通过，以下游戏项目全部待测，不预填“通过”。

## 安装与准备

1. 新建独立测试实例/测试存档。使用本次对应加载器ZIP内的`mods`，不要混放旧本体；也可以仅替换本体并自行准备对应前置。Forge最低47.3.22、Java17；NeoForge21.1.248、Java21。两版前置分别列在ZIP内，不要交叉使用。
2. 先不装额外战斗模组，开启作弊，创造模式取本模组物品。使用`/purifiedundead contract grant @s`、`/purifiedundead warrior grant @s ferin`，将古老民族之契、费林放入正确Curios槽。执行`/purifiedundead talisman set @s 10`解锁五段，再用`/purifiedundead status`确认。
3. 基线不用追忆、不装其他战士、去掉力量/暴击装备，使用普通近战武器；另准备秽鬼之守护用于联动。费林技能开关默认开启；在控制设置中找到费林相关按键并设置需要的绑定。
4. 准备空旷白天地形、多个不会被第一下打死的高血量怪物、上下平台、实心墙。建议录制60帧视频并保留整个`logs/latest.log`。使用存活静止目标测准，再测移动目标。
5. 远程准备可以用原有秽鬼之守护；超过其距离的项目，需要能合法增加近战距离的测试工具/模组。记录它的名称与设置，不能因普通武器够不到就把“未触发”当成新剑气缺陷。

## 必测行为

| 编号 | 操作 | 预期结果 |
| --- | --- | --- |
| 01 发射位置 | 静止、跑动、跳跃、急转身时分别触发 | 从左侧光点附近发射，允许离散方块中心与连续光点的小差异；不再固定从准星中心飞出 |
| 02 五段形状 | 连续触发五段，第一/第三人称各录一次 | 保留原五段扇形/环形、尺寸、颜色；不会因碰撞容差把模型放大；远处旧段不被新段替换 |
| 03 三维瞄准 | 命中上方、下方、侧面及贴脸目标 | 剑气朝实际目标碰撞箱转向；不会只水平飞行、垂直方向出现NaN或反转 |
| 04 远距到达 | 对约5、15、40、100格的静止合法目标触发 | 距离越远可提高速度；20TPS下名义到达不超过3秒；额外路程约4格，不因旧段生命周期过早消失 |
| 05 高速漏判 | 将`flightArrivalTicks`设为1或0后重启；让远处窄目标处于路径中 | 即使单刻跨过目标仍能命中，不仅检测起终点；0不崩溃、不除零 |
| 06 容差 | 用目标边缘擦过刀光，再让目标明显远离整片剑路 | 贴边更容易命中；明显偏离仍应漏空，追踪目标不是保底伤害 |
| 07 追踪 | 目标受击后横向跑动/缓慢上升，另放邻近诱饵 | 有适量转向，只追踪原目标；不是突然换敌或无限绕圈；高速移动允许躲开 |
| 08 飞行中死亡 | 发射后用另一来源杀死目标，诱饵放在旁边 | 已发出剑气按最后方向飞完有限剩余距离，不改追诱饵 |
| 09 无新目标续段 | 首段命中，后续挥空续段；分别让原目标存活/死亡，并转动视线 | 存活优先追上一目标；死亡后的新一段从新光点沿当前视线发射 |
| 10 新目标接替 | 连段间实际命中新目标 | 新一段朝新目标；已经在飞的旧段继续自己的目标，不被覆盖 |
| 11 穿墙 | 发射后在路径上留实心墙，墙后放目标 | 保留穿墙；方块不提前销毁剑气 |
| 12 多目标/去重 | 同一路径放多个怪物，使用高血量目标观察环形/追踪重叠 | 可以命中多个合法目标；同一段同一目标只伤害一次，下一段可再次伤害 |
| 13 原数值 | 固定武器与目标，关闭额外伤害因素；再分别加入费林追忆/海尼尔标记 | 保留原段系数、独立暴击、追忆和标记计算；不因连续扫掠多结算一次 |
| 14 原剑联动 | 使用秽鬼之守护的自身剑气触发协同 | 原武器剑气保持原样；随后费林协同使用本次新发射逻辑，不递归触发 |
| 15 合法目标 | 试队友、自己的宠物、关闭PVP的玩家和免疫/无伤害攻击 | 不绕过旧过滤；未真正造成合格伤害的攻击不启动新召唤 |
| 16 生命周期 | 远处剑气尚在飞时死亡、换维、退出再进、旁观、关闭费林技能、创造卸下契约 | 所有旧剑气伤害与视觉停止；不重登补伤害；冷却不被这些动作刷新 |
| 17 大型目标 | 普通巨型Boss、多部件目标以及自定义hurt的Boss | 原大型/多部件补触发保留；录下实际触碰点及是否产生剑气；免疫攻击不能误启动 |
| 18 重登与旧存档 | 在1.1.1hotfix测试存档的副本升级，攻击中退出再进入 | 无读档崩溃、不重放历史剑气，契约/成长/原配置仍在 |

## 联机、配置与性能

- 两个客户端连接同版本服务器，各自触发五段：双方均看到正确归属、方向和独立剑气，无第二个重复影像或额外伤害。
- 在约100/200毫秒延迟下录制：飞行应连续，有界预测后接受服务端纠正；初次发射仍有确认延迟，不要求绝对零延迟。检查急转时是否明显跳变、极近距离短寿命刀光是否看不见。此项是本轮重点待测风险。
- `flightTurnDegrees=0`：完全不再转向；恢复6：有限追踪。`flightMinimumSpeed=0.25/1/4`与`flightArrivalTicks=0/20/60`组合各测试一次；每次编辑后重启，记录实际配置。
- 在世界坐标较大处（例如十万格）测试方向与画面，局部偏移同步不应出现明显精度抖动。
- 目标卸载/跨维度后不强加载追踪、不追同ID的其他实体；已确认丢失的这一发转直线，有限寿命结束。
- 逐步增加至5—10名玩家同时连段，记录服务器MSPT/TPS、客户端帧率、实体数与停止攻击10秒后的残留情况。不要把一个人不卡视为多人性能通过。
- 最后在原整合包副本中复测03、05、07、14、16、17和联机项目。记录战斗/属性/光影模组版本。此部分不需要车万女仆或YSM。

## 可选开发回归（给能构建源码的人）

根目录是Forge，`1.21.1neoforge版本`是NeoForge工程。先核对本机JDK路径，原脚本的机器路径可能需本地适配。只在独立开发实例运行：

```powershell

& ./scripts/gradle.ps1 --offline test
& './1.21.1neoforge版本/scripts/gradle.ps1' --offline test

# 独立开发服务端全套回归；不要指向正式存档
$audit = (Resolve-Path scripts/audit-server.gradle).Path

& ./scripts/gradle.ps1 --offline runServer -I $audit -I $chain
& './1.21.1neoforge版本/scripts/gradle.ps1' --offline runServer -I $audit -I $chain
```

检查新`FerinFlightMotionTest`八项：到达预算、0刻/垂直、转向与有限追踪、目标丢失、非法数值、高速薄目标、容差与真实漏空、三角面空角。游戏回归新增`FERIN_FLIGHT_OK`，测试独立伤害快照、远距真实碰撞、去重、消失和取消。还应出现原有`FERIN_LIFECYCLE_OK`、`FERIN_LARGE_MOB_OK`、`GUARDIAN_WAVE_OK`及hotfix/完整回归标记，不能只看Gradle成功。服务端测试类不包含在普通安装包内，安装ZIP不会自动运行这些开发检查。
