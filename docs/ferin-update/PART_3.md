# 骑士寂夜 · 女仆虚影

Forge 1.20.1 与 NeoForge 1.21.1，候选版本 `1.2.0-ferin.12`。费林视觉实体新增同步字段，客户端与服务端使用协议 16。

服务器在每段协同剑气释放时，从骑士寂夜的最后一次有效切片提取显示字段。女仆在魂符中时沿用该切片。无女仆绑定、女仆死亡或绑定已注销时，外观数据为空。旧切片缺少的显示选项使用女仆模组默认值。采样包括模型、YSM 材质、有限的漫游变量、惯用手、背包外观类型、展示物品 ID、显示开关和流体外观。背包内的物品栈与女仆的战斗数据均不进入视觉同步。

客户端在该段起手期间，按光点处刀光使用的同一个起点和释放方向绘制虚影。用于调用女仆渲染器的代理只在客户端持有，不加入世界实体列表，不推进实体逻辑。攻击状态按释放时间采样，命中、归属和击杀始终由已有的服务端剑气处理。

## 玩家设置

在「控制」中为「切换骑士寂夜女仆虚影」指定按键，默认未绑定。该键切换本机看到的虚影并保存至 `config/purified_undead-client.toml` 的 `[knightNocturne]` 节。

| 配置 | 默认值 | 效果 |
| --- | --- | --- |
| `showEcho` | `true` | 显示虚影，关闭后协同剑气和增伤仍照常生效 |
| `specialAnimations` | `true` | 允许已注册且匹配骨架的动作参与绘制，关闭后使用模型原生表现 |
| `echoScale` | `0.85` | 虚影相对于原模型的尺寸，可设为 0.25 至 2.0 |

## 骨架与后续动画制作

1.2.0-ferin.8 建立了五个段号的播放入口。1.2.0-ferin.9 加入第一段正式动作 `animation.ferin.combo_one`。开启专属动作时，带有关节和右手持物挂点的 Gecko 酒狐模型以右手持原版铁剑，从左肩前跨身斜斩至右下。经典酒狐和其他无法匹配的模型继续走原有路径。

第一段的躯干、肩、肘和手腕从 Blockbench 动画资源采样。原版铁剑挂在渲染代理的主手，车万女仆负责绘制。游戏根据实际持物骨和第一段刀光的释放方向校正剑身，挥剑最多领先起手刀光 0.16 游戏刻。开发客户端以固定的亚刻时间截取第一段，覆盖起势、过中线、伸臂和收势。

- 经典 Bedrock 酒狐使用独立的头、身体、四肢根骨。匹配时还核对耳朵连到头、裙子经坐姿旋转骨连到躯干。局部转动施加在单次绘制内，结束后恢复共享模型。
- 车万女仆内置 Gecko 酒狐使用 `MRoot → Root` 等辅助骨，手臂从 `UpperBody → Arm → RightArm → RightForeArm → RightHand` 等链传递。匹配实际加载的父子关系。皮肤 ID、纹理或额外装饰骨不决定是否适配。专用代理先运行模型自身控制器，再叠加匹配的旋转，绘制后还原。
- 客户端扩展可实现 `EchoAnimations.Motion` 并调用 `EchoAnimations.register`。在 `matches` 中选择模板或校验自己的层级，在 `sample(stage, age, pose)` 中按 1–5 段号和以游戏刻计的浮点时间写出局部旋转增量（弧度）。模型保留自身枢轴，不从参考模型复制绝对关节位置。没有对应片段时返回 false，且不写入旋转。按注册顺序使用首个可用片段。
- YSM 经车万女仆自带的 YSM 渲染桥使用模型、纹理、漫游变量和原生挥击状态。YSM 的通用定位接口只公开手、腰、头等定位骨，本版尚不能借此向任意 YSM 模型注入完整骨骼姿态。YSM 2.6.5 自带大正女仆的主模型里，`MRoot` 上方另有 `GuiRoot`。没有足够骨架信息时保留其原生渲染。
- 已与车万女仆 1.5.3 核对经典模型 `authors_and_credits:wine_fox_maid`、Gecko 模型 `geckolib:winefox` 和同骨架材质变体 `geckolib:winefox_blue`。模型、贴图、第三方动作从玩家已安装的模型包加载。参考了史诗战斗适配的网格选择、骨架与图层分工，项目没有引入史诗战斗依赖。[酒狐官方项目](https://github.com/TartaricAcid/WineFoxModel) · [史诗战斗适配渲染器](https://github.com/xssfww/EpicFight_TouhouLittleMaid/blob/master/src/main/java/net/EFTLM/EF/Render/PatchedLivingMaidRenderer.java)

## YSM 酒狐与小伙伴的前三段虚影

骑士寂夜在正式采样时读取女仆当前的 YSM 模型、材质和外观变量，将可用的 Gecko 变体 ID 写入切片。例如，大正女仆酒狐的 `skin_white` 对应 `geckolib:winefox_blue`。映射依据是 YSM 2.6.5 和车万女仆 1.5.3 的内置资源，覆盖 `wine_fox/` 下的 22 个模型目录。玩家更换配色后，下一次采样会更新映射。魂符沿用封存时的切片，升级前已入符的女仆在放出并重新采样后获得新映射。

前三段起手时，客户端按切片中的 ID 取本机模型，并在新建虚影时检查持剑骨链。只有开启专属动作且实际模型可用时才播放第一段袈裟斩、第二段回挑或第三段下劈。第四、五段、未知贴图、带有未映射造型变量的皮肤或缺少对应资源的客户端，沿用原 YSM 外观和动作。真实女仆继续使用玩家选择的皮肤。

背包种类、流体外观、展示开关、女仆同步的展示物和头部装备分别采样。代理以单件物品还原外观，保留自定义模型值、染色、耐久、附魔光泽和最多 16 层旗帜图案。具体绘制位置和可见性由所选皮肤及车万女仆的装备图层决定。背包库存和第三方任意私有物品数据不进入切片。

## 连段第二段 · 双手回挑

`animation.ferin.combo_two` 承接第一段落在右下方的收势，沿用第一段末帧各关节的姿态。左手向右收拢接住剑柄，左肩带动躯干向左转，在剑经过身前时双手一同向左肩前上挑。铁剑只挂在右手，左手关键帧按剑柄后端的位置求解。

第一、二段分别采样自己的动作片段与起手刀光轨迹，剑先行最多 0.16 游戏刻。第二段仅在具备持剑及支撑手骨链的适配模型上使用。两版隔离世界分别以原生 Gecko 酒狐远景核对完整刀光，并以 YSM 蓝白酒狐近景对照一段末、二段起、合握、过中线和收势。

## 连段第三段 · 双手下劈

`animation.ferin.combo_three` 的首帧沿用第二段末帧的 16 个骨骼姿态。酒狐从左肩前双手举剑过顶，再随下劈伏身。以水平朝向为参照，侧视末帧的剑身向前下方倾斜 35°。这个角度随释放方向一同俯仰。

播放专属第三段时，光点上的刀光在举剑 1.2 游戏刻后开始显形。动作和起手刀光使用原第三段弧线的同一区间，铁剑最多先行 0.16 游戏刻。飞行剑气沿用原来的完整弧形、轨迹和命中判定。

## 回归范围

两版独立服务端用实际女仆和饰品测试佩戴、采样、装备外观往返、未知配色与造型变量回退、死亡和解绑，检查 `NOCTURNE_YSM_SNAPSHOT_OK`、`NOCTURNE_ECHO_SNAPSHOT_OK`、`NOCTURNE_MAID_OK` 和 `FERIN_FLIGHT_OK`。

两版客户端借助 `scripts/ferin-visual.gradle` 核对车万女仆实际注册的 22 个模型、37 种材质和持剑挂点，检查 `NOCTURNE_WINE_FOX_PACK_OK`、`NOCTURNE_ECHO_CLIENT_OK`、`FERIN_DYNAMIC_CLIENT_OK` 及分段截图。第一段用白色大正酒狐切片、展示南瓜和大背包。两版发布 JAR 均已在隔离的正式加载器中与车万女仆 1.5.3、YSM 2.6.5 一同启动并完成资源重载。测试使用预设的皮肤选择数据。
