# 费林更新

**1.2 正式版**收录了截至 `1.2.0-ferin.27` 的费林更新，适用于 Forge 1.20.1 与 NeoForge 1.21.1，网络协议为 16。[中英对照更新日志](../RELEASE_V120.md)

### ferin.27 纯净触碰镶嵌与 Better Combat 连续挥剑

安装 Tetra 后，在加工台的宝石镶嵌槽放入一枚纯净触碰，消耗 1 点完整度，获得 512 点耐久和 2 点攻击伤害。近战武器同时获得「秽鬼守护」。主手挥动时会放出秽鬼之守护的五种幻影剑气之一，服务端按这次挥击的持武攻击力、蓄力和原有战斗修正结算。工作台、全息球和装备提示均能显示词条。

安装 Better Combat 并启用其「按住攻击」选项后，持续按住攻击键，每次主手出招都能发出一道剑气。秽鬼之守护本体也支持这种挥剑方式，可以单独配合 Better Combat 使用。[联动范围、扩展适配和实测](TETRA.md)

### ferin.26 双版本整合复核

以已交接的 `7df1cbb`（ferin.16）为起点，复核 ferin.17 至 ferin.25 的材料、饰品与追忆、护甲与刷怪蛋、纯化铸造器、秽鬼之守护及其挥剑剑气，以及手记和右键转化。ferin.26 修复了以下问题。

| 入口 | 修复与验证方法 |
| --- | --- |
| 怨念污秽右键 | 普通生物、铁傀儡和唤魔者共用一个实体交互入口。客户端接受交互，阻止同一按键继续触发净化，服务端读取当前已装备的契约并决定转化及扣件。游戏回归覆盖同刻摘戴、旁观、已驯服目标、重复交互与生成取消。 |
| 活村民的食物栏 | 秽鬼村民继承原版僵尸村民，无法接收村民的八格私有库存。主动转化时，每堆物品连同自定义名称随替身一起掉落。用取消第二堆掉落的事件测试回滚，原村民、原物品和怨念污秽均能保留。 |
| 纯化铸造器 | 静态外壳改用区块烘焙模型。检查了四个朝向各自的待机与工作外观、原版方块展示实体和约 72 格外的实物。铸造、容器、漏斗和存档仍由原方块实体负责。 |
| 秽鬼之守护手持 | 所有物品堆共用装饰动画时钟。先提交剑身与附魔光泽，再绘制半透明气旋并继承父骨骼变换。用调换骨骼顺序的资源包实测了完整 100 刻的绕刃动画。 |
| 秽鬼之守护挥剑剑气 | 客户端开始追踪时，服务端随实体发送一次发射原点和用手，供表现层还原偏移与旋转进度。回归让射手在发射后换手，观察者在剑气已飞出 8 格且看不到射手时接收实体。 |
| 自定义武器网格 | 五种武器幻影和女仆虚影的费林剑共用客户端模型读取器。每个资源上限 512 KiB、2048 个四边面，完整校验顶点、UV 和法线后才交给渲染。高优先级资源格式错误时回退至下一份有效模型。 |

成品逐文件与 ferin.25 对照，两版所有贴图、模型、配方和手记资源均一致。此次沿用已有注册 ID、存档格式、网络协议和服务端命中结算。旧美术资产保存在[旧贴图归档](../../旧贴图/README.md)。基线的战斗与联动设计见[ferin.16 交接](HANDOFF.md)。

Forge 通过 168 项单元测试，NeoForge 通过 169 项，均无跳过。两版独立服务端分别逐种验证了 18 和 19 种右键转化，并取得剑气、铸造器、手记和净化的游戏内通过标记。两版成品分别在有、无车万女仆的隔离客户端进入世界，覆盖实际右键扣件、四类槽位、64 篇手记、旁观剑气、外壳远景与半透明绕刃。远景采用固定机位对照，移除铸造器后，四个客户端画面中央的方块都随之消失。

### ferin.25 饰品槽、纯净物品、手记与转化

古老民族之契、不死战士、白巫女遗物和流浪日记四种 Curios 空槽各有独立的 16×16 灰色剪影。两张物品图重绘为 64×64，纯净触碰保留白发祈祷侧影，纯净禁果则用蓝银色弧钢环绕金色果实。[新旧物品与槽位对照](curios-items.png) · [新旧物品原图](../../旧贴图/纯净触碰与纯净禁果/)

白巫女手记补齐了纯化铸造器、石板残片、解语密文文本、闪耀的守护宝具、解语密文残片制纸和手记本身的工作台配方。七种可合成的秽鬼追忆分别显示对应石板、解语密文文本、产物与石板返还说明。白巫女遗物新增「骑士寂夜」。安装车万女仆时会显示绑定、女仆饰品、协同攻击与女仆祭坛材料，缺少女仆模组时显示另一段手记。[两种手记文案与配方实机截图](diary-pages.png)

佩戴古老民族之契后，手持怨念污秽右键对应的普通生物即可转化。Forge 共 18 种，NeoForge 共 19 种，其中包括 1.21.1 的沼骸。村民和鸡也能通过右键转化。生存模式每次成功消耗一个怨念污秽，创造模式可重复使用。已驯服的马受原有保护。

两版手记分别核对了全部 25 个固定工作台配方和 7 个追忆合成示例。Forge 的 164 项、NeoForge 的 165 项单元测试通过。两版专用服务器逐种触发了转化交互，两版成品 JAR 也分别在装有和未装车万女仆的客户端中重载资源、打开 Curios 和翻阅手记。

### ferin.24 挥剑起点与概率

秽鬼之守护的剑气从握剑一侧飞出，逐渐汇入原有的 15 格命中线。五种武器每次各有 20% 的机会显现。[出手位置与概率核对](guardian-wave/README.md)

### ferin.23 挥剑剑气

每次挥剑显现五种武器之一。费林的剑与西丽亚的巨锤翻转飞行，西丽德的链锤、格洛特的战锤和尤里乌斯的战枪沿出手方向直进。原剑气的紫色渐变、粉白亮边和细丝分别贴在刃口、锤缘与枪脊上，拖影跟随这些部位扫过的位置。[五种效果、模型与实机记录](guardian-wave/README.md)

### ferin.22 手持模型

秽鬼之守护以 ferin.21 的 128×128 背包图标为正面底稿，重建了像素手持模型。剑尖朝上时，左缘是铁红色主刃，右缘是带折角的灰黑剑脊。长伪刃、分层钩爪和镂空剑首沿用图标的轮廓，侧面的剑格和皮革握柄收薄。第一人称按原版钻石剑的握点和斜率定位，右手剑尖伸向屏幕右上，左手镜像。[像素设计三视图](blighted_guardian_pixel_views.png) · [成品正、侧、背视图](blighted_guardian_model_views.png)

手持、掉落物和展示框共用一个 GeckoLib 模型。气旋有前后表面和侧边，由独立骨骼驱动，每 100 游戏刻绕剑身旋转一周。暗灰紫的褶面、灰紫中间色和冷灰亮边有各自的不透明度，带身约为 33% 至 66%，两端最淡处约为 23%。武器实体先绘制，气旋随后单独进行透明混合，附魔光泽落在武器实体上。Blockbench 工程内嵌手持图集、背包图标参考和循环动画。[可编辑模型](blighted_guardian.bbmodel) · [游戏内五秒循环](blighted_guardian_vortex.gif)

两版均以成品 JAR 进入隔离测试世界，检查了资源重载、物品栏、第一与第三人称左右手、附魔光泽、掉落物和展示框。固定机位下每五刻采样一次，覆盖完整一周。间隔一周切换白墙和黑墙，确认背景可透过气旋，剑身仍遮住背景。Forge 的 159 项、NeoForge 的 160 项单元测试通过，两版专用服务器回归也取得了游戏内通过标记。
