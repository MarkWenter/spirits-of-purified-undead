# 费林更新

当前候选为 **1.2.0-ferin.23**，适用于 Forge 1.20.1 与 NeoForge 1.21.1，协议 16。本版更新秽鬼之守护挥出时的剑气。每次挥剑显现五种武器之一。费林的剑与西丽亚的巨锤翻转飞行，西丽德的链锤、格洛特的战锤和尤里乌斯的战枪沿出手方向直进。原剑气的紫色渐变、粉白亮边和细丝分别贴在刃口、锤缘与枪脊上，拖影跟随这些部位扫过的位置。[五种效果、模型与实机记录](guardian-wave/README.md)

### ferin.22 手持模型

秽鬼之守护以 ferin.21 的 128×128 背包图标为正面底稿，重建了像素手持模型。剑尖朝上时，左缘是铁红色主刃，右缘是带折角的灰黑剑脊。长伪刃、分层钩爪和镂空剑首沿用图标的轮廓，侧面的剑格和皮革握柄收薄。第一人称按原版钻石剑的握点和斜率定位，右手剑尖伸向屏幕右上，左手镜像。[像素设计三视图](blighted_guardian_pixel_views.png) · [成品正、侧、背视图](blighted_guardian_model_views.png)

手持、掉落物和展示框共用一个 GeckoLib 模型。气旋有前后表面和侧边，由独立骨骼驱动，每 100 游戏刻绕剑身旋转一周。暗灰紫的褶面、灰紫中间色和冷灰亮边有各自的不透明度，带身约为 33% 至 66%，两端最淡处约为 23%。武器实体先绘制，气旋随后单独进行透明混合，附魔光泽落在武器实体上。Blockbench 工程内嵌手持图集、背包图标参考和循环动画。[可编辑模型](blighted_guardian.bbmodel) · [游戏内五秒循环](blighted_guardian_vortex.gif)

两版均以成品 JAR 进入隔离测试世界，检查了资源重载、物品栏、第一与第三人称左右手、附魔光泽、掉落物和展示框。固定机位下每五刻采样一次，覆盖完整一周。间隔一周切换白墙和黑墙，确认背景可透过气旋，剑身仍遮住背景。Forge 的 159 项、NeoForge 的 160 项单元测试通过，两版专用服务器回归也取得了游戏内通过标记。
