# 费林更新 · 材料图标修补

候选版本 `1.2.0-ferin.17`，承接[上一候选的开发交接](HANDOFF.md)。Forge 1.20.1 与 NeoForge 1.21.1 使用相同的十张 32×32 RGBA 图标，覆盖十七件物品。每张图以该物品原有的入包贴图为参考，分别生成底稿，再按物品整理轮廓、色阶与透明边缘。

| 图标 | 旧图对应的问题 | 保留的识别特征 |
| --- | --- | --- |
| 污秽碎片、怨念污秽 | 已为 32×32，但碎片有 259 个半透明像素，怨念有 312 个 | 狭长碎片左下的亮核、完整火团两侧的分叉 |
| 污秽红宝石、墓穴泞尘 | 16×16 | 红宝石左侧亮面、灰白粉堆的宽底和暗红颗粒 |
| 纯净结晶、净化弧钢、净化弧钢锻造模板 | 64×64 | 白晶与金色火纹、弧钢的蓝金缠纹、石模板上的蓝色上箭头 |
| 解语密文残片、解语密文文本 | 1280×1232、1264×1264 | 残片的撕口、整页的卷角与三行密文、深红污迹 |
| 石板残片 | 1264×1248 | 倾斜石面、刻痕和深色侧边。七种铸造石板继续引用同图，并沿用各自物品的附魔光效 |

实际资源位于两版各自的 `src/main/resources/assets/purified_undead/textures/item/`。与上一候选 JAR 对照，两版的 assets 文件集合相同，内容发生变化的均为上述十张 PNG。原有模型引用、注册 ID 与配方继续生效。
