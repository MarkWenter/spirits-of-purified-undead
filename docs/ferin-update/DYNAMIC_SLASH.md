# 费林动态刀光试作 · 1.2.0-ferin.2

2026-11-18，Forge 1.20.1 / NeoForge 1.21.1，网络协议 15。联机客户端与服务端须同时更新。

## 游戏表现

五段沿用既定剑路：斜下斩、反向回挑、纵向下劈、倾斜周身回旋、450°纵向回旋。
每次攻击在服务端确认的光点发射位置展开一层短促挥斩，飞行刀光同时逐渐成形，
两者短暂重叠。发射残影保持起始朝向，飞行刀光沿现有追踪方向移动。

飞行刃面采用12帧、30帧每秒的循环紫焰贴图，保持紫色内层、粉色与暖白外刃。
内缘起伏、内部细线和有限长度的紫色拖尾随时间变化，末尾最多3刻渐隐。
本版采用程序化曲面和PixelFX烘焙贴图，五段都拥有独立轨迹；未新增Blockbench骨骼资源。

此方案从释放刻开始移动剑气。原地挥斩与飞行重叠，避免把新的视觉准备动作加入伤害延迟。
极短飞行结束后只保留到挥斩结束的视觉实体，期间不会继续推进运动或处理伤害。
完整飞行环线继续对应原有攻击范围。

## 实现与边界

- FerinEntity同步不可变的发射格坐标、小数偏移和初始方向。位置偏移保留小数精度，
  新数据字段需双方使用协议15。视觉实体不进入存档。
- FerinSlashMesh分别提供launch和flight。飞行几何成形时间与流动时间分开，
  外侧攻击曲线保持稳定，内缘持续变化；原有sample调用保留历史行为。
- FerinSlashEffects仅在客户端生成40片短拖尾并选择图集帧。它不接收输入包，
  不改写伤害、目标或玩家数据。
- 贴图256×1536，解压RGBA约1.5 MiB，共用一张图集。无逐刻图片上传，
  无逐帧贴图生成，也无额外粒子实体或无界轨迹历史。
- 发射阶段短暂增加一份曲面绘制，飞行阶段增加40片拖尾。
  大量玩家同时攻击时的实际帧耗需要多人环境测量。
- 使用现有透明自发光渲染。测试时发现原版云层会遮挡部分透明刀光，
  最终画面测试关闭了测试实例的云层。生产渲染仍保留场景深度遮挡。
- 高延迟时按服务器时间推进动画，已经过去的挥斩不会从头重播。
  本次没有加入本地攻击预测。

## 资源复现

scripts/generate-ferin-wake.mjs使用本地.tools/pixelfx/src/core/math.js的周期噪声和
tools/lib/png.mjs输出图集。依赖PixelFX 0.3.1（MIT，Patch / Hugo Duprez），
这些工具仅在制作阶段运行。五段形状由项目现有Java剑路确定。

## 验证入口

- 单测覆盖发射消失、非法时间、成形后内缘持续变化及外缘位置稳定，
  并运行既有单元测试。
- FerinFlightSmoke通过服务器真实发射入口核对固定发射姿态、飞行分离、
  独立伤害快照、命中去重、有限寿命和取消。
- scripts/ferin-visual.gradle仅启用FerinDynamicClientSmoke，使用开发实例中
  diary-validation存档，逐帧捕获五段。运行期间会移动测试玩家并调整测试世界时间，
  只能在开发实例中使用。它是确定性视觉测试，不能替代真实多人网络测试。
- 本轮原始日志、截图索引、校验值和动态预览在outputs/ferin-dynamic。
  运行通过标记为FERIN_DYNAMIC_CLIENT_OK与FERIN_FLIGHT_OK。

## 本轮结果

Forge 150项、NeoForge 151项单测通过。两版客户端均输出FERIN_DYNAMIC_CLIENT_OK，
服务器均输出FERIN_FLIGHT_OK，并完成原有服务器回归。最终生产包检查确认包含动态贴图，
Forge内嵌MixinExtras，测试类未混入。游戏截图为开发测试实例的确定性视觉场景，
尚未进行多人压测及其他显卡、光影包组合验证。
