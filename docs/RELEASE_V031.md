# v0.31.0 · 初版

首个公开版本，以已验证的 `0.31.0-dev` 构建为发布基线。

- 古老民族之契、八组不死战士饰品、护身符升级及正式奖励获取流程。
- 费林五段刀光协同攻击，实际攻击区域与轨迹匹配，支持宽松连段输入。
- 饰品加护、姐妹移动能力与摔落伤害减半、伊莱恩黑红魔弹。
- 获得饰品和升级音效，满级独立提示；佩戴战士后契约污秽说明变化。
- 减少空闲扫描、重复计算和临时对象分配，修正特效实体追踪范围并补充状态清理。

102 项现有回归测试通过，405 个刀光采样的顶点及颜色与优化前一致。本地专项基准中刀光计算耗时降低约 63%、临时内存分配降低约 61%；这不等同于游戏 FPS 提升比例。

费林初版使用刀光表现，不显示角色与剑模型。长期多人压力测试、所有第三方模组兼容性尚未完整验证。
