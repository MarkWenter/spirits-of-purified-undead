# v0.47.0 · 石板更新兼容性与性能修复

两版同步修复高频数据读取、工作方块无效计算、JEI 重复注册及异常输入边界。保留原有注册 ID、存档结构、配方、属性数值、美术和白巫女手记正文。

- 莉莉手记效果判定直接读取追忆标识，避免每次反序列化八个物品；当次修改立即生效，不使用可能过期的玩家缓存。
- 已领取费林追忆后停止重复扫描背包；奖励待补发时保留原有补发行为。
- 铸造配方建立原料索引；空槽快速返回；进度不再每刻标记区块待保存，也不再每刻拼接配方字符串。批量加工、余料搬移和燃料规则不变。
- JEI 刷新复用已注册的配方对象，重复同步不再持续新增同一配方；离开服务器清理客户端配方状态。
- 手记菜单在绑定物品被替换后拒绝继续点击或转移，避免其他背包操作造成过期菜单访问。
- 配方配置及网络同步增加结构、容量和数值检查；无效配置保留原文件、停止加工，不删除库存。可选 JEI 刷新、动态光源和无甲联动的接口异常隔离，避免持续重复失败。
- Forge 保持最低 47.3.22，并包含此前 0.46.3 的资源标识接口修复。

验证范围、测量与限制见 [兼容性审查](COMPATIBILITY_AUDIT_047.md)。客户端与服务端需一起更新。仍需满足现有 Curios、GeckoLib、Patchouli 前置版本要求；JEI 和亡灵联动模组仍为可选。

本次修复不能证明所有整合包或整机卡死均已解决；没有在玩家正式存档上执行回归。
