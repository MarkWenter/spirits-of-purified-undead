# 涤净亡魂 1.1.1hotfix

本次为1.1「污秽之雨」的兼容性与稳定性修复，汇总此前四轮hotfix候选。保留原有玩法、正常伤害倍率、配方、注册ID、存档键与美术资源；网络协议仍为13。

## 更新内容

- 调整污秽降水着色器的顶点阶段、雾函数引用与局部变量，减少AMD + Oculus报告涉及的共享着色器冲突面；保持对应游戏版本的原版雾语义及原有雨雪颜色公式。
- 天气着色器不可用时受控回退，资源重载后可重试；隔离可选视觉和外部兼容功能的失败，保留核心玩法检查。
- 加强饰品死亡保留、满背包补发和奖励提交的故障恢复，未知物品记录不因解码失败丢弃，防止恢复部分成功后重复发放。解码单条数据使用独立副本。
- 加强生物转换的装备与乘骑恢复。源实体已经移除后，保留已发布替身和装备；不可安全恢复的异常仍明确报告。
- 对外部异常战斗数值增加边界检查，包括伊莱恩魔法倍率乘后溢出；异常情况下保留原有限事件伤害，不生成无穷伤害魔弹，正常倍率与概率保持。
- 减少满背包反复恢复时的无效库存复制，为失败同步增加退避，保留逐项提交、真实插入回滚及故障恢复能力。

## 安装与升级

替换对应Minecraft与加载器版本的旧本体JAR，mods中仅保留一个涤净亡魂本体。前置要求不变，客户端与服务器建议一同更新。升级前备份存档和配置；本次不要求新建世界，也不支持将Forge存档跨版本转换为NeoForge存档。

## 验证范围

两版均重新构建，运行单元测试、完整独立开发服务器回归及正式JAR客户端启动/着色器注册/资源重载检查。完整日志与校验值见本版本验证记录。

本机使用NVIDIA，AMD + Oculus修复仍需报告者实机回测，不能保证所有显卡、资源包或光影组合均兼容。此前NeoForge首次测试出现原版模型加载异常及随后Placebo重复注册错误，后续单独启动通过；根因尚未确认，本次复验结果另有记录。
