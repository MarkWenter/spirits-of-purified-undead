# 第一部分历史记录：纯化铸造器（0.44.0—0.44.2）

适用 Minecraft 1.20.1 Forge 与 Minecraft 1.21.1 NeoForge。此目录独立记录石板更新，不并入净化更新；本阶段不更新白巫女手记。

## 当时实现

- 新工作方块「纯化铸造器」，注册 ID `purified_undead:purification_foundry`。
- 单格石质方块，正面为石中剑图案，区分正面、侧面、背面、顶部和底部；放置时正面朝向玩家，支持四个水平方向。
- 界面采用原版风格灰色面板及槽框，上方原料、左侧燃料、右侧燃料、下方成品。法腾的灰绿色衣袖与手位于左槽上方，伊莱恩的紫黑色衣袖与手位于右槽下方。
- 中央中空剑身为从上向下填白的进度条，满进度抵达剑尖；服务端工作状态驱动正面剑的明亮贴图。当前没有加工配方，正常游玩中保持待机。
- 四个槽位保存于方块数据，关闭界面不丢失；拆除方块时掉出库存。使用镐开采方块可获得方块本身。

## 定向漏斗交互

「左、右」均指玩家面对方块正面时的左右，随方块朝向旋转，不固定为世界东、西。

| 接入面 | 行为 |
| --- | --- |
| 上面 | 原料输入 |
| 左侧 | 左燃料输入 |
| 右侧 | 右燃料输入 |
| 下面 | 仅提取成品 |
| 正面、背面 | 不提供漏斗输入或提取 |

三个输入槽暂不增加物品种类过滤，也不沿用熔炉燃料表。成品槽仅供取出。背包 Shift 点击暂统一送入原料槽；左右燃料可手动放入或由各自方向的漏斗送入，不根据未定义的燃料种类猜测去向。

## 合成

固定有序配方，产出 1 个：

```text
原石  铁剑    原石
原石  红石粉  原石
原石  原石    原石
```

每个原石位置均接受原石或深板岩原石，允许混用；不接受普通石头或其他剑。

## 第一部分阶段限制（已由第二部分实现）

本阶段不添加加工配方、燃料种类、燃料消耗、加工时长、额外产物或经验奖励。放入物品仅存储，不自动消耗或生产。工作进度展示接口为后续配方实现保留，开发测试会单独设置进度验证画面，测试代码不进入发布包。

## 美术

0.44.2 保持 16×16 方块像素密度，将石材换为平整规则石砖；正面的剑嵌入带有石沿与阴影的凹槽。左右手臂图集仍为 128×52、各 64×52，以界面原生像素显示；伊莱恩右手比 0.44.1 下移 4 像素。

中央剑柄和护手改为 32×24 透明像素装饰，与手臂同尺度显示。剑身为中空轮廓，进度从剑身顶部向下填充纯白，抵达剑尖时完成；剑柄与护手保持固定。使用内置 imagegen 制作装饰和石砖贴图，剑身轮廓及填充仍为代码图形。生成记录见 [ART.md](ART.md)。0.44.0 为功能基础，0.44.1 为第一轮像素风调整，0.44.2 为本轮中空进度与嵌剑石砖调整。
