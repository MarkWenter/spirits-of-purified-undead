# 0.54.0 白巫女手记新增内容

本次按用户文档补充书内内容，不改变石板玩法和物品悬停说明。

## 目录与条目

新增目录 `slate_enhancement`（石板强化），排序为 4。原有 `purified_items`（净化物品）继续使用原 ID 和排序 3。`future`（其他内容）保留原红色问号图标，排序改为 5，位于全部目录之后。

新目录内依照文档顺序加入 14 个条目：纯化铸造器、石板残片、铸造的石板残片、解语密文残片、解语密文文本、格洛特／西丽亚与西丽德／尤里乌斯／狼／伊莱恩／海尼尔／法腾／费林的秽鬼追忆、闪耀的守护宝具。图标均引用现有注册物品；统一的铸造石板条目以格洛特变体为展示图标，正文覆盖全部战士变体。

两版均保留原有 39 个条目；“秽鬼之守护”和“莉莉手记”只插入文档新增的说明段落，原背景文字与配方页不删除。文档重复的旧句沿用原文，其中“纯净触碰”的名称与既有注册物品一致，“但在崩坏的世界中”不增加重复的“在”字。

## 文本与颜色

逐条核对新正文与文档中的文字，移除仅用于说明排版的“贴图是”“灰色字体”“红色字体”等标注，并转换成实际图标与颜色。保留原句及标点，在句子或分句边界分页。灰色使用 Patchouli `$(7)`，红色使用 `$(c)`，不同段落之间显式重置颜色，防止普通说明继承回忆颜色。

没有重建现有目录，没有新增物品或配方。手记合成、首次赠书、已有存档中的书籍 ID 均不变。最终共 6 个目录、53 个条目、130 页。
