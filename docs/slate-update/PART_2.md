# 石板更新 · 第二部分（0.45.1）

追忆效果已于 0.52.0 更新，当前变化见 [增强记录](ENHANCEMENTS_052.md)；下表保留第二部分发布时的历史规则。

## 纯化铸造器

上槽为原料 A，下槽为原料 B／成品；左槽只能放怨念污秽，右槽只能放已有的纯净结晶（需求中称「净化结晶」）。每份配方默认消耗两种燃料各 1 个；每批默认 400 游戏刻，即 20 秒，与一次酿造相同。上槽按配方决定消耗或保留，下槽原料会消耗。

| 上槽 A | 下槽 B | 成品 | 消耗 A |
| --- | --- | --- | --- |
| 煤炭 ×1 | 煤炭 ×1 | 钻石 ×2 | 是 |
| 铁锭 ×4 | 金锭 ×4 | 下界合金碎片 ×1 | 是 |
| 紫水晶碎片 ×1 | 墨囊 ×1 | 回响碎片 ×1 | 是 |
| 金锭 ×2 | 木棍 ×1 | 钟 ×1 | 是 |
| 钻石 ×16 | 凋零骷髅头颅 ×1 | 下界之星 ×1 | 是 |
| 格洛特／姐妹／尤里乌斯／狼／伊莱恩／海尼尔／法腾战士饰品 ×1 | 石板残片 ×1 | 对应铸造的石板残片 ×1 | 否 |

一次同时完成可容纳的最大数量，受原料、燃料及成品最大堆叠数共同限制。例：上下各 64 煤炭、两种燃料各 64，第一批消耗上下煤炭各 32 和两种燃料各 32，产出 64 钻石。上下剩余各 32 煤炭合并成上槽 64 煤炭，下槽显示 64 钻石；下一批需重新分配原料。存档和拆除会保留／返还内部余料。不会把多出的成品丢在地上，也不会一次生成超过一槽容量的成品。

对于消耗上下两种原料的配方，按实际燃料和成品容量计算最大批量后，必须至少耗尽一种原料，或两份余料为可合并且合计不超堆叠上限的相同物品，才会启动。7 铁锭＋7 金锭不启动；16 铁锭＋18 金锭产出 4 下界合金碎片，剩余 2 金锭移到上槽。燃料不足导致两种余料无法合并时同样不启动。带不同名称／数据的物品不能合并。保留上槽模板的配方继续内部保存下槽余料；旧存档内部余料仍会保存和返还。

漏斗方向沿用第一部分：上面输入 A，正面视角左侧输入怨念污秽，右侧输入纯净结晶，下面仅取已完成的成品，正面／背面不传输。B 需要手动放入下槽；下面的漏斗不会提前抽走 B。Shift 点击燃料会进对应槽，其他原料先送上槽，上槽已有物品时支持把下槽配方材料送入下槽。配方或批量改变会重新计时；卸载后未完成进度重新开始，完成时才消耗物品。

## 材料与合成

- 石板残片：八个原版石头围绕一个污秽碎片，有序合成。
- 解语密文残片：主世界与下界宝藏箱每次生成战利品有 25% 概率加入 1—5 个；兼容采用 `chests/` 战利品表路径的遗迹模组。末地、怪物和方块掉落不添加。已经生成过战利品的旧箱子不会重新补货。其他模组完全自定义开箱流程的情况需对应适配。
- 解语密文文本：九个密文残片铺满合成台，有序合成。
- 密文残片可无序 1:1 合成纸，无反向配方。
- 七种铸造石板：通过上表保留战士饰品的配方获得；共享石板材质，并显示附魔光晕。
- 七种普通秽鬼追忆：对应铸造石板＋密文文本，无序合成；仅消耗文本，石板返回合成格。
- 闪耀的守护宝具：七种铸造石板无序合成，消耗七块石板。属于白巫女遗物，佩戴时最大生命值提高 100%，与现有属性系统叠加，卸下后撤销此修正；遵守现有白巫女遗物总开关与全局效果倍率。
- 费林追忆：同一玩家历史上获得其余七种追忆后发放一次；背包满时等待空位，死亡／重登不重复发放。背包、光标、已装备手记中的追忆均可记录。

| 追忆 | 装有该追忆的手记佩戴后 | 额外依赖战士的强化 |
| --- | --- | --- |

| 西丽亚与西丽德 | 血量从不低于 30% 降到 30% 以下且存活时，抗性提升 III、力量 III、生命恢复 III 持续 50 秒；冷却 180 秒 | 无 |
| 尤里乌斯 | 疾跑伤害 +20%；额外移动速度每提高 10% 再加 5% 伤害（按完整档位，原版疾跑本身的 30% 不重复计为额外增速） | 无 |

## 配置文件

启动一次游戏或服务器后生成：

- `config/purified_undead-slate.toml`：宝箱概率、追忆伤害比例、游泳加成、异常状态概率和时长、姐妹增益与冷却、抢夺等级、费林伤害、守护宝具生命值倍率。
- `config/purified_undead-foundry.json`：12 条默认加工配方。以服务器配置为准，修改后重启服务器；单机需重新进入世界。支持其他模组的物品注册 ID。

配方示例：

```json
{
  "recipes": [
    {
      "top": "minecraft:coal",
      "topCount": 1,
      "bottom": "minecraft:coal",
      "bottomCount": 1,
      "output": "minecraft:diamond",
      "outputCount": 2,
      "consumeTop": true,
      "leftFuel": 1,
      "rightFuel": 1,
      "ticks": 400
    }
  ]
}
```

`consumeTop: false` 保留上槽模板，仅要求上槽达到 `topCount`，不会要求一批中每个成品各有一个模板。其余数量是每份配方的用量，批量时按份数扣除。多个配方匹配时使用列表中第一条。字段必须齐全，物品必须已注册；数量与燃料为 1—64，产出不得超出该物品的最大堆叠数，时间为 1—32767 刻。非法条目会记录警告并跳过；文件损坏时停止加工，保留库存，不覆盖配置。此版支持物品 ID 与数量，不解析标签、NBT 或数据组件条件。

第二部分物品贴图恢复为此前生成的原始版本，不再额外降为 16×16；方块贴图和前置版本保持不变。白巫女手记资源没有更新。

## JEI

可选安装对应版本 JEI，查看纯化铸造器的上下原料、左右燃料、产物、耗时及上槽是否保留；对两种燃料查询用途也会列出铸造配方。追忆合成另有工作台分类，明确标注铸造石板保留。进入服务器时同步实际配置配方，支持自定义条目；修改配置仍需重启服务器／重新进入单机世界。最多支持 4096 条配方。未安装 JEI 不影响正常游玩。NeoForge 已补齐全部 19 件物品和纯化铸造器的创造栏索引。
