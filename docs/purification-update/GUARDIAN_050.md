# 秽鬼之守护 · 0.50.0

## 精魂兼容根因

上一版只开放了 Malum 附魔适用性。实际源码判定还要求武器属于可收割精魂标签，才能在伤害事件中暴露目标精魂，并在死亡时按 Malum 的规则生成精魂。玩家归属没有丢失；剑气继续使用 playerAttack(player)。

Forge 1.20.1 为 `malum:soul_hunter_weapon`（tags/items），NeoForge 1.21.1 为 `malum:soul_shatter_capable_weapon`（tags/item）。通过 replace=false 合并，仅添加秽鬼之守护。没有修改所有玩家伤害的标签、没有强制改成镰刀或弹射物，没有调用两次掉落方法，也不重写外部 capability / attachment。

遵循 Malum 原有规则：未配置精魂的目标、无魂目标或配置禁止的刷怪笼生物仍可能不掉精魂。精魂劫掠负责额外收益，缚灵负责魔法伤害；两项附魔本身不自动给任意武器收魂资格。与 Malum 原生收魂武器一致，加入名单后无需额外附魔也有基础收魂资格。剑气期间若切换主手装备，Malum 仍按自身命中时装备规则处理，不临时替换玩家背包以伪造武器。

## 手感与安全边界

每刻 1 格，七格七刻；视觉尺寸乘 1.25。命中线段对目标边界的扩张从 0.8 改为 1.0，周边查询和已加载区块检查相应扩大至 1.3。保留完整路径碰撞，不因速度改变漏过目标；最远距离仍按原点与目标最近点限制。

保留即时预测、返回去重、服务端判伤、主人失效与到期清理、上下文 finally 恢复。无新增全局扫描、逐刻反射或硬前置。生产包不包含测试模组与验证类。

## 验证

可选环境实际加载 Forge Malum 1.6.7 / Lodestone 1.6.4.1，以及 NeoForge Malum / Lodestone 1.8.2。`GUARDIAN_SOUL_DROPS_OK` 使用真实死亡事件，检查附魔秽鬼之守护剑刃和剑气击杀产生的 Malum 精魂实体，不仅检查铁砧输出或物品标签。

`GUARDIAN_WAVE_OPTIMIZATION_OK` 检查七刻七格及扩大后的侧向命中；保留墙体、友军、独立伤害、箭矢倍率及格洛特/伊莱恩/海尼尔/费林回归。`GUARDIAN_CLIENT_OK` 核对本地即时显示、延迟去重、渲染与到期清理。两版完整构建与单测、基础和可选环境回归日志随交付保存。
