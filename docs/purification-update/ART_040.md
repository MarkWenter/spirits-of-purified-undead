# 0.40.0 · 无垢护甲图标与秽鬼之守护外观修订

## 修改

- 四件无垢护甲的物品图由透视立体图改为正面平面像素图，统一 32×32。保留深色金属与金蓝纹路；穿戴模型及两张护甲 UV 贴图完全不变。
- 秽鬼之守护从 128×128 精细线稿重制为 32×32 的粗像素图。加宽连续剑身，简化为三块连接的灰白结晶、深灰带状装饰，以及可辨认的剑格、剑柄与剑首。保留铁灰剑身与铁红刃口。
- 新剑图实际不透明部分占 219 像素，四向连通检查仅有一个连通块，没有孤立像素。透明度只有 0/255，避免半透明毛边。
- 保留原版 `item/handheld` 挤出模型的侧面厚度。第三人称比例从 0.85 增至 1.0；第一人称同时调整比例、平移和角度，将剑向画面内部移动，并检查左右手及 FOV 70/90 的实际显示。

## 不变的内容

没有改动伤害、攻速、耐久、附魔、合成、锻造、饰品槽位或护甲效果。白巫女手记和护甲穿戴贴图与 0.39.0 保持逐字节一致。

## 美术来源

由内置 imagegen 根据上一版物品图重新设计；使用已获许可的裁切、最近邻尺寸规范化和透明边缘整理。最终贴图位于两版 `src/main/resources/assets/purified_undead/textures/item/`：`immaculate_helmet.png`、`immaculate_chestplate.png`、`immaculate_leggings.png`、`immaculate_boots.png`、`blighted_guardian.png`。模型位置为 `models/item/blighted_guardian.json`。

提示词见 [art-prompts-040.json](art-prompts-040.json)。原始生成图与预览保存在本机 `art/purification-update/040/`。

## 验证

分别使用 Forge 47.4.23 / Java 17 和 NeoForge 21.1.248 / Java 21 构建，并运行客户端模型检查；保存物品栏、第三人称、第一人称右手 FOV 70/90 和左手截图。检查剑的实际模型仍有 1/16 方块厚度；检查五张图的尺寸、透明度及两版本一致性。发布包比对要求所有主代码 class、配方、穿戴护甲纹理与手记保持不变。

本机验证记录分别保存于两个版本目录的 `验证记录/0.40.0/`。

最终剑模型共有 82 个四边形。第一人称右手旋转 `[0,-70,20]`、左手 `[0,110,-20]`，两侧平移 `[-1.5,6.7,0.2]`、比例 `0.62`；将较宽的新剑形完整纳入画面，第三人称比例独立设为 `1.0`。
