# 验证记录（0.37.0）

两版分别使用 Forge 47.4.23 / Java 17 与 NeoForge 21.1.248 / Java 21 构建。

## 服务端实测

开发专用 `PurificationServerSmoke` 在真实专用服务器中验证：

- 3 种瓶型 × 基础/红石/萤石的 9 个酿造配方。
- 三种药效的等级、持续时间与天蓝色；6 次火药/龙息瓶型转换。
- 水瓶不能代替粗制药水；延长与强化不能叠加。
- 两张有序配方实际匹配、产出数量及错误中间材料的拒绝。
- 净化实际扣除 4 个怨念污秽并给予 4 个结晶，普通升级与满级后均可用。
- 材料不足、空堆叠重复调用、完成前摘下契约均不发放奖励。

测试发现 NeoForge Curios 的同刻缓存会保留刚变更的装备查询结果，因此净化结算改为检查实际堆叠。测试不进入发布 JAR。

## 客户端实测

两版分别启用 RyoamicLights 与对应 Oculus/Iris + Complementary Reimagined r5.6.1：

- 光源 15→3、原版方块亮度仍为 0、摘下后移除光点及动态照明。
- 检查碰撞箱尺寸为 0、不可拾取/推动/碰撞、无流体推动。
- 人工设置实心障碍后，连续推进光点，确认穿过方块且未消失。
- 强制清理客户端实体，确认下一刻恢复且位置差小于 0.25 格。
- 玩家跨区块传送后，光点保持 4 格以内；不产生跨画面插值。
- 普通实体计时不再推进运动，客户端管理器独立推进；玩家隐身不清除光点。
- 新物品模型加载正常，在游戏内显示贴图、名称和天蓝色药水。

另在两版不安装任何动态光源或光影扩展时重复客户端检查。没有进行大型多人整合包压力测试，不保证第三方实体剔除模组或任意光影包都兼容。

## 手记保持不变

打包时将新 JAR 内 Patchouli 章节、条目、书本定义、GUI 与日记图标和旧 0.36.0 JAR 逐项比较，要求完全相同。“净化更新”仅记录在此独立目录。

完整日志、截图、测试数量和 JAR 校验值保存在本机两版的 `验证记录/0.37.0`。

## 0.38.0 验证补充

- JEI 15.62.0.217（Forge）与 19.57.0.450（NeoForge）：各 15 条唯一配方，输入逐条调用真实酿造逻辑核对输出；物品着色为指定天蓝色。
- 独立服务器检查九条酿造、六条瓶型转换、效果等级与时长、两个有序配方、升级与满级消耗等防重复交易。
- 自定义受伤大体型模拟生物漏发 Living 事件时能够补触发，免疫攻击不触发；末影龙部件解析到本体；观察不会重复使用。
- 三张纹理均为 64×64 RGBA；两版相同。白巫女手记资源与 0.37.0 成品逐字节比较。
- 第三方怪物未逐个实测；没有怪物清单，因此保留这一验证范围限制。
