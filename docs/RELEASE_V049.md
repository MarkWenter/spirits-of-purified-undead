# v0.49.0 · 秽鬼之守护即时剑气与灵灾附魔

Forge 1.20.1 与 NeoForge 1.21.1 同步更新；两端须同时升级，网络协议为 8。

- 挥剑时客户端立即显示剑气，不等待服务端往返。服务端仍独立验证武器、蓄力、伤害、命中与资格；服务器返回的同次剑气不重复显示。
- 飞行速度由每刻 0.5 格提升至 1.75 格，射程由 3 格改为 7 格，4 刻完成。连续路径检测保留不穿墙、每目标每发仅命中一次、队友和宠物过滤。
- 剑气额外接受 Apothic Attributes 的箭矢伤害倍率（发射时取值一次）。伤害源仍是玩家近战，不添加弹射物标签，不触发仅弹射物可触发的效果；箭速属性不转为伤害。
- 保留 120% 近战倍率、原版蓄力、独立协同暴击、跳劈/疾跑状态及伊莱恩、海尼尔、格洛特、费林联动。
- 正确补齐灵灾 **Malum** 的镰刀附魔兼容，并额外支持 **精魂劫掠 Spirit Plunder** 与 **缚灵 Haunted**，遵守原有互斥规则。上一版将灵灾误识别为 Goety，旧 Goety 兼容保留。本次不增加必选前置。
- 增加预测实体过期、主人失效、未加载区块、重复请求及异常数值保护；不扫描全世界、不主动加载区块、不使用预测实体造成伤害。
