# v1.0 — 正式版本编号

将已经完成兼容性审查的 v0.56.0 定为 v1.0。Forge 1.20.1 与 NeoForge 1.21.1 的模组内部版本均为 `1.0`，移除开发版后缀。使用作者本次提供的秽鬼化图像作为本体模组列表图标。

玩法、注册 ID、存档、配置、配方和网络协议不变。与上一版逐文件比较，只有版本元数据及新增 icon.png 不同；业务类和游戏资源保持相同。

两版完成构建和单元测试（Forge 127 项、NeoForge 128 项），并使用真实发布 JAR 验证正式加载器主菜单及修改目标类加载。本轮没有重复宣称全套玩法回归；业务逻辑沿用 v0.56.0 已通过的验证。

公开文件仅使用本体 JAR；本地完整依赖 ZIP 不作为 Modrinth 模组文件上传。安装包未发现本机用户路径、工作目录或常见凭据格式，未混入日志、存档与开发测试类。提供的 PNG 仅含图像数据块，不含文本和 EXIF。

Forge 最低版本仍为 47.3.22。NeoForge 为 21.1.248。Curios、GeckoLib、Patchouli 等原有依赖与可选联动规则不变，Forge 内嵌 MixinExtras，勿安装 slim 构建。
