# v0.52.1 · 正式安装包启动修复

修复 Forge 0.52.0 在正式安装环境中启动崩溃的问题。请用新版替换旧的涤净亡魂 JAR，不要同时保留两版。

- 原因：新增追忆兼容代码的 refmap 使用了点分隔类名，而 Mixin 在正式运行时按斜杠分隔类名查询，导致击杀条件注入找不到目标方法。
- 修复 Forge 全部五组相关映射及 searge 上下文，涵盖掉率、战利品条件、击杀进度和字段访问。保留原有注入校验，不跳过功能。
- 增加映射格式回归检查，避免此类错误再次进入构建。
- NeoForge 1.21.1 使用官方名称，不使用该 Forge refmap，未发现相同缺陷；同步提供重新构建并验证的 0.52.1。

验证：旧 Forge 发布 JAR 在独立正式实例中复现同一崩溃；新 Forge 47.4.23 和 NeoForge 21.1.248 客户端均到达主菜单并加载全部相关注入目标。两版服务端开发回归通过，Forge 125 / NeoForge 126 项单元测试通过；Forge 的真实星月刻蚀板条件兼容专项通过。未运行用户正式存档，也未验证所有整合包组合。

Forge 最低支持仍为 47.3.22；前置、协议 10、玩法参数、贴图、配方和存档格式保持原样。白巫女手记正文不更新。详情见[石板更新修复记录](slate-update/HOTFIX_0521.md)。
