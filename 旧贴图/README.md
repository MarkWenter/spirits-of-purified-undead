# 旧贴图与重绘成品

按批次和候选版本保存游戏实际使用的 PNG。以下文件夹均位于模组资源目录之外。每个文件以物品资源路径的末段命名；本次归档内的 Forge、NeoForge 对应图像逐字节一致，每个版本状态保存一份。

| 批次 | 原图 | 成品 | 每个状态的张数 |
| --- | --- | --- | ---: |
| 材料 | [ferin.16](材料/16-重绘前/) | [ferin.17](材料/17-重绘后/) | 10 |
| 饰品、手记与追忆 | [ferin.17](饰品/17-重绘前/) | [ferin.18](饰品/18-重绘后/) | 27 |

姐妹、法腾和伊莱恩的追忆另存了两次中间稿。[三张初稿](饰品/18-追忆初稿/)记录角色细节修订前的样子；[三张轮廓调整前的贴图](饰品/18-追忆轮廓调整前/)已修正姐妹的头巾与翅膀、法腾的长布面具和伊莱恩遮住五官的发束。最终入包的三张采用同系列的深青描边，见[饰品成品](饰品/18-重绘后/)。本目录共保存 80 张 PNG。

还原某件物品时，从对应状态取同名 PNG，复制到目标加载器工程的 `src/main/resources/assets/purified_undead/textures/item/`。石板残片与七种铸造石板沿用同一张 `slate_fragment.png`。后续若再次重绘，请另存新版本，以便继续取回这里的每一份图。
