# 旧贴图与重绘成品

姐妹、法腾和伊莱恩的追忆另存了两次中间稿。[三张初稿](饰品/18-追忆初稿/)记录角色细节修订前的样子；[三张轮廓调整前的贴图](饰品/18-追忆轮廓调整前/)已修正姐妹的头巾与翅膀、法腾的长布面具和伊莱恩遮住五官的发束。最终入包的三张采用同系列的深青描边，见[饰品成品](饰品/18-重绘后/)。

ferin.19 的两个目录保留了游戏内的 `textures/` 路径。每个目录含四张护甲物品图、两张穿戴图、一张刷怪蛋叠图和三张铸造器纹理。刷怪蛋另存了[加宽纹路前的初稿](无垢护甲、铸造器与刷怪蛋/19-纹样加宽前/)。恢复 ferin.18 的铸造器外观时需一并取回该版的方块模型及渲染实现。

ferin.19 和 ferin.20 共用同一套铸造器几何与 UV。替换对应批次的三张 PNG 即可切换石壳外观，分别用于待机、工作和方块粒子。本目录共保存 104 张 PNG。

材料与饰品的归档按文件名还原到目标加载器工程的 `src/main/resources/assets/purified_undead/textures/item/`。ferin.19 批次按归档中的相对路径还原到 `assets/purified_undead/` 下。石板残片与七种铸造石板沿用同一张 `slate_fragment.png`。后续若再次重绘，请另存新版本，以便继续取回这里的每一份图。
